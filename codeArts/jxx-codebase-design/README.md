# jxx-codebase-design

设计深模块（deep module）的共享词汇 — 模块、接口、深度、接缝（seam）、适配器（adapter）、杠杆（leverage）、局部性（locality）。大量行为隐藏在干净接缝处的小接口之后。

## 何时使用

当用户想设计或改善模块接口、发现深化机会、决定接缝（seam）位置、使代码更可测试或 AI 可导航时使用，或当其他技能需要深模块词汇时使用。

## 相关技能

- `/jxx-improve-codebase-architecture` — 发现深化机会
- `/jxx-tdd` — 测试驱动开发
- `/jxx-domain-modeling` — 领域建模
