# jxx-triage

将 issue 与 external PR 推过 triage 状态机——分类（categorise）、验证、必要时 grill，并编写 agent 可执行的简报。

## 何时使用

当用户有堆积的 bug 报告、功能请求需要 triage，或想将 issue 推过状态机时使用。仅适用于未创建的 issue，不要对 `/jxx-to-tickets` 产出的工单再做 triage。

## 相关技能

- `/jxx-grilling` — 充实请求时使用
- `/jxx-domain-modeling` — 锐化领域术语
- `/jxx-setup-matt-pocock-skills` — 前置配置
