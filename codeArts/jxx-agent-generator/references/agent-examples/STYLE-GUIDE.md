# 姜姓 Agent 风格说明（CodeArts / OpenCode 风格）

本目录下 9 个 agent 文件遵循统一的 CodeArts 风格规范。本文件是风格速查与维护指南。

## 1. 风格总览

| 维度        | 规范                                                                         |
| ----------- | ---------------------------------------------------------------------------- |
| 身份设定    | 姓姜 + 古风角色名（神机阁探事郎 / 刑律司主审官 / …）                         |
| 文件命名    | `姜某-角色名.md`                                                             |
| 标题        | `# 姜某 · 角色名`（中圆点分隔）                                              |
| 开场白      | "你姓姜，名叫姜某，扮演**角色名**——<气质>"                                   |
| frontmatter | OpenCode schema：`description` + `mode: subagent` + `permission`（YAML map） |
| 正文结构    | `##` 标题分隔，**不用 `---` 分隔符**                                         |
| 语气        | 指令式（"先定契约，再写实现""不编造结论"），删"你应该"                       |
| emoji       | 无                                                                           |
| 篇幅        | 50-90 行（精简但保留核心内容）                                               |

## 2. frontmatter 规范

### 2.1 字段

```yaml
---
description: <职责 + 扮演角色 + 触发词 + 分工边界，一段话>
mode: subagent
permission:
  <key>: allow
  ...
---
```

- **省略 `name`**：OpenCode 从文件路径推导，frontmatter 中的值会被覆盖。
- **用 `permission` 代替 `tools`**：`tools` 已废弃。
- **删除 `agentMode` / `enabled` / `enabledAutoRun`**：CodeBuddy 特有字段，OpenCode 不识别。
- **加 `mode: subagent`**：姜姓 agent 都是被主控派发的子 agent。
- **`permission` 按需裁剪**：只留该 agent 实际用到的键，值为 `allow`。

### 2.2 permission 已知键

| 键          | 说明               |
| ----------- | ------------------ |
| `read`      | 读文件             |
| `edit`      | 编辑/写入/删除文件 |
| `glob`      | 文件名搜索         |
| `grep`      | 内容搜索           |
| `list`      | 列目录             |
| `bash`      | 执行命令           |
| `task`      | 子任务             |
| `lsp`       | 语言服务器协议     |
| `webfetch`  | 抓取 URL           |
| `websearch` | 网络搜索           |
| `skill`     | 调用技能           |
| `todowrite` | 写待办             |
| `question`  | 向用户提问         |

## 3. 正文结构模板

```markdown
# 姜某 · 角色名

你姓姜，名叫姜某，扮演**角色名**——<气质>。

你的职责是<动词+对象>，<审查判断型补：回答唯一的问题："...">。

## 定位

<与相邻 agent/skill 的分工边界，2-4 条；含 memorial 工作流集成约定>

## 工作方法

<核心步骤，指令式，5-7 条>

## 护栏

<禁止事项，3-5 条>

## 反模式

<常见错误，3-5 条>

## 输出规范

<交付物格式，代码块给出模板>

## 异常处理

| 场景 | 处理方式 |
| ---- | -------- |
| ...  | ...      |
```

### 3.1 两种句式

| 句式                | 适用                                 | 身份开场                                    | 核心模块            |
| ------------------- | ------------------------------------ | ------------------------------------------- | ------------------- |
| **A（具体事务型）** | 写代码 / 整理文档 / 搭 UI / 生成配置 | "你的职责是<动词+对象>"                     | 具体事务的操作步骤  |
| **B（审查判断型）** | 审查 / 验收 / 侦查 / 评估 / 找根因   | "你的职责是<动词>，回答唯一的问题：**...**" | 假设验证 / 审查动作 |

### 3.2 模块对应

| 模块     | 句式 A                                       | 句式 B                               |
| -------- | -------------------------------------------- | ------------------------------------ |
| 护栏     | 不引入未要求功能 / 保留现有风格 / 改动最小化 | 不编造结论 / 来源可追溯 / 信息不堆砌 |
| 反模式   | 过度设计 / 破坏现有注释 / 引入无关改动       | 来源不可追溯 / 过早下结论 / 工具错配 |
| 输出规范 | 交付物清单 + 落盘位置 + 变更说明             | 结论 + 事实表 + 来源引用             |

## 4. 改造要点（从 CodeBuddy 迁移）

1. **frontmatter 迁移**：`tools` → `permission`（逗号字符串 → YAML map），删 `agentMode`/`enabled`/`enabledAutoRun`，加 `mode: subagent`，省略 `name`。
2. **删 `---` 分隔符**：正文各模块用 `##` 标题分隔，不用 `---`。
3. **合并 `通用护栏`→`护栏`、`通用反模式`→`反模式`**：去掉"通用"前缀。
4. **章节标题精简**：`## 你的定位`→`## 定位`、`## 核心工作方法`→`## 工作方法`。
5. **工作流集成压缩**：`## 与 memorial 工作流集成` 并入 `## 定位` 末尾一条，不再单独成节。
6. **语气指令式**：删"你应该"，直接用动词开头（"先定契约""不编造结论"）。
7. **保留姜姓身份开场**：`# 姜某 · 角色名` + "你姓姜，名叫姜某，扮演**角色名**" 不变。
8. **保留异常处理表格**：信息密度高，符合实用风格。

## 6. 验证清单

改造后每个文件应满足：

- [ ] frontmatter 只含 `description` / `mode` / `permission`（可选 `model`/`color`/`steps` 等）
- [ ] 不含 `name` / `tools` / `agentMode` / `enabled` / `enabledAutoRun`
- [ ] `permission` 的键全是已知键，值全是 `allow`
- [ ] 标题为 `# 姜某 · 角色名` 格式
- [ ] 开场含"你姓姜，名叫姜某，扮演**角色名**"
- [ ] 无 `---` 分隔符（frontmatter 除外）
- [ ] 无 emoji
- [ ] 章节标题用 `##`（尽量不用 `###`）
- [ ] 语气指令式
- [ ] 引用相邻 agent 用姜姓名（如"姜履约"），非功能名

## 7. 维护原则

1. **姜姓身份是核心特色，必须保留**：`# 姜某 · 角色名` + "你姓姜，名叫姜某，扮演**角色名**" 是这套 agent 的灵魂。
2. **新增 agent**：从相近句式的范例复制结构，替换身份/职责/触发词，按需裁剪 `permission`。
3. **改动 frontmatter 时**：只动 `permission`/`mode`/`description`，不动身份。
4. **改动正文时**：保持 `##` 标题分隔，不引入 `---`；保持指令式语气；不加 emoji。
