# jxx-agent-generator

按"OpenCode/Crush SKILL.md 风格 + 统一 frontmatter + 功能性写作模板"生成或改造 agent 文件。产物为 `<skills-dir>/<name>/SKILL.md`，兼容 Agent Skills 开放标准。

## 何时使用

当用户想新建 agent、给 agent 加功能定位、改造现有 agent、从 CodeBuddy 迁移到 OpenCode、或统一一批 agent 的风格/规范时使用。

## 相关技能

- `references/frontmatter.md` — OpenCode frontmatter 字段约定
- `references/identity.md` — 功能性写作模板与规范
- `references/examples.md` — 9 个 agent 范例摘要
- `references/agent-examples/` — 9 个完整 agent 文件，可直接复制使用
