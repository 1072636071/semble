# jxx-grill-with-docs

grill 以打磨计划或设计，同时创建文档（ADR 和词汇表）。有代码库时使用，grill 过程中自动维护领域模型。

**核心约束：文档先行，代码后行。** grill 期间只做追问和文档创建，禁止修改代码。

## 何时使用

当用户有代码库并想通过 grill 打磨想法时使用。

## 工作流

1. **初始化** — 读取现有 `CONTEXT.md` 和 `docs/adr/`
2. **Grill 循环** — 交替执行追问和领域建模，术语/决策确定后立即记录到文档
3. **收尾** — 用户确认后总结文档变更，此时才可进入代码实施

## 相关技能

- `/jxx-domain-modeling` — 领域建模
- `/jxx-grilling` — 无代码库时的纯追问
- `/jxx-grill-me` — 无文档创建的纯追问
