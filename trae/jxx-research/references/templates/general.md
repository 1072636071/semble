# general — 通用报告

不限领域的通用结构。其他模板不适配时使用此模板。

## 标准节

| 节 | 必填 | 内容 |
| -- | ---- | ---- |
| **摘要** | 是 | 报告目的、主要发现、核心结论 |
| **背景** | 是 | 报告的起因、上下文、要解决的问题 |
| **主要内容** | 是 | 灵活分节，按主题逻辑组织。如涉及多方面，每方面独立一节 |
| **结论** | 是 | 总结关键洞察和后续行动建议 |
| **参考来源** | 是 | 所有引用的来源链接 |

## 灵活分节原则

`主要内容` 部分根据实际情况拆为多节。命名应描述内容而非笼统的"第一部分"：

- 好：`现有流程分析`、`竞品策略对比`、`用户反馈汇总`
- 坏：`第一节`、`分析`、`内容`

## 使用规则

1. 模板是起点，不是牢笼。如果某节对当前报告无意义，省略。如果需要额外节，增加。
2. 必填节不可省略。
3. 节顺序可调。
4. 摘要最后写 —— 完成正文后再提炼，确保覆盖所有关键发现。
5. 来源引用统一格式：行内 `（来源：<路径 | URL>）`，集中引用在 `参考来源` 节列出编号列表。
