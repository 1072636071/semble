# jxx-research

调研主题、收集资料并生成结构化报告。支持两种模式：

- **自由模式**（默认）：agent 自主决定调研方式和输出格式，保留来源可追溯纪律
- **严格模式**：按模板生成结构化 Markdown 报告到 `docs/report/`，触发词：生成报告/严格模式/按模板

## 何时使用

当用户需要调研某个主题、收集文档或 API 事实、技术选型评估、撰写报告、或将阅读工作委托给后台 agent 时使用。

## 输出位置

- 自由模式：agent 自主决定
- 严格模式：`docs/report/{模板前缀}-{主题slug}.md`
