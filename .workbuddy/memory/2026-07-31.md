# 2026-07-31 工作日志

## Git 分支与凭据排查
- 本仓库（jwikis-skills）远程（Gitee `origin`）实际有 2 个分支：`master` 和 `optimize/jiang-xiaodai-agent`。本地曾只缓存了 master。
- AGENTS.md 声称"双远程（GitHub v8 + Gitee origin）双推送"，但当前 `git remote -v` 只配置了 Gitee `origin`，无 GitHub 远程。
- 沙箱内 git 拉取 Gitee 私有仓库必然失败：根因是**沙箱无 Gitee 凭据**，wincred 在无 tty 下无法读取本机 Windows 凭据管理器，报 `could not read Username`；之前 PortableGit `etc/gitconfig.lock` 残留锁只是叠加因素，删锁后仍因凭据缺失失败。→ 沙箱内无法 fetch 私有仓库，必须在本机执行（wincred 可弹窗/读凭据），或用户提供 Gitee 私人令牌（PAT）配进 `credential.helper store` / `remote set-url` 后才能在沙箱拉取。
- 切换分支可靠命令（本机执行）：
  `git fetch origin "refs/heads/optimize/jiang-xiaodai-agent:refs/remotes/origin/optimize/jiang-xiaodai-agent"`
  然后 `git checkout --track origin/optimize/jiang-xiaodai-agent`
