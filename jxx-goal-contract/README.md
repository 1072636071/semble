# jxx-goal-contract

目标契约固化子技能——将模糊任务收敛为可执行的 GOAL.md 契约。支持多目标隔离存储（`.goals/{name}/` 目录），支持重复已完成目标和追加到已有目标。继续中断目标由 jxx-goal-execute 直接处理。

三种模式：默认推进（低风险+领域熟悉，直接给推荐版）、发现优先（低风险+陌生领域，先调研再实施）、Grilling（高风险或用户要求，逐维度追问）。

## 何时使用

- /jxx-goal-mode 路由分发到本技能
- 用户说"写目标""定契约""固化目标""goal contract""重复目标""重做目标"
- 需要将模糊需求转化为可执行契约
- 需要重复或追加已有目标

## 目标存储

所有目标存储在工作区 `.goals/` 目录下，按目标名称隔离：

```
.goals/
├── _index.md          # 目标索引
├── linkcheck/
│   ├── GOAL.md        # 契约
│   ├── PROGRESS.md    # 执行进度（含固化日志）
│   └── EVIDENCE.md    # 交付证据
├── blog-site/
│   └── ...
```

## 模式

| 模式     | 适用场景         | 特点                        |
| -------- | ---------------- | --------------------------- |
| 默认推进 | 低风险+领域熟悉  | 直接给推荐执行版+编号选择题 |
| 发现优先 | 低风险+陌生领域  | 先调研再实施                |
| Grilling | 高风险或用户要求 | 逐维度追问                  |

## 契约质量保障（v4.1.0）

| 机制                | 说明                                                                |
| ------------------- | ------------------------------------------------------------------- |
| 否决门              | 9 道否决门，任一不通过不可写入 GOAL.md                              |
| 自检-修正内循环     | 默认推进模式：草稿→自检否决门→修正→独立检查→输出推荐版              |
| 执行-检查上下文隔离 | 生成和检查在不同 task/subagent 中完成，检查 agent 只看契约原文+规则 |
| 契约深度下限        | Acceptance ≥ 3 条、Constraints ≥ 3 条、Budget 缺一不可等            |

## 目标操作

| 操作 | 说明                                                        |
| ---- | ----------------------------------------------------------- |
| 新建 | 创建 `.goals/{name}/`，走契约固化流程                       |
| 重复 | 复制已有 GOAL.md，重置进度，重新执行                        |
| 追加 | 在已有契约上追加新需求                                      |

> 继续中断目标不经过本技能——由 jxx-goal-mode 直接路由到 jxx-goal-execute 断点恢复。

## 相关技能
