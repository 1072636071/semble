# Skill Name: z-translation

[TOC]

## Overview

高质量中英互译技能，支持文档、代码注释、技术术语、Markdown 文件的翻译。遵循信达雅原则，保持格式不变，术语一致。支持术语表查询、翻译风格参考、长文档分段处理。

## Features

- 中英互译，自动识别源语言和目标语言
- 技术术语表（~150 条），确保术语翻译一致
- Markdown 格式保留翻译
- 代码注释翻译（保留代码不翻译，JSDoc/docstring 类型标注不翻译）
- 技术文档专业翻译（首次出现附原文）
- 长文档分段翻译，保持上下文连贯
- 混合语言内容智能处理
- 翻译风格参考（正式文档/API 文档/博客/代码注释）
- 文件级翻译（读取源文件 → 翻译 → 写入目标文件）

## Prerequisites & Setup

无额外依赖。翻译由 LLM 直接执行，无需安装工具或配置环境变量。

## Local Testing & Usage

直接在 Agent 对话中使用，例如：

```
翻译这段文本：Hello World
将以下文档翻译为中文：[文档内容]
翻译 src/README.md 文件
把这个文件国际化
```

## Trigger Prompts & User Scenarios

- **场景 1：文本翻译**
  - 用户提示："翻译这段话"
  - 预期行为：识别语言方向，执行翻译，保持格式

- **场景 2：文档翻译**
  - 用户提示："把这个 README 翻译成英文"
  - 预期行为：读取文件，翻译内容，保持 Markdown 格式

- **场景 3：代码注释翻译**
  - 用户提示："翻译代码中的注释"
  - 预期行为：仅翻译注释，代码逻辑不变

- **场景 4：术语查询**
  - 用户提示："repository 怎么翻译"
  - 预期行为：查询术语表，给出标准译法

- **场景 5：国际化/本地化**
  - 用户提示："i18n 这个项目"、"本地化这个文件"
  - 预期行为：识别为国际化需求，批量翻译文件

- **场景 6：长文档翻译**
  - 用户提示："翻译这份技术规范文档"
  - 预期行为：按语义段落分段翻译，保持术语一致性

## Input & Output Specification

**Inputs**

- 源文本（直接提供或文件路径）
- 源语言（可选，自动检测）
- 目标语言（可选，默认中英互转）

**Outputs**

- 翻译后的文本，保持原文格式和结构
- 文件翻译时输出完整内容，不省略任何部分

## Bundled Resources

| 资源                        | 用途                                      |
| --------------------------- | ----------------------------------------- |
| `references/terminology.md` | 技术术语表（~150 条），翻译时确保术语一致 |
| `references/style-guide.md` | 翻译风格参考，不同场景的风格指导          |

## Limitations & Known Issues

- 超长文档需分段翻译，可能影响上下文连贯性
- 双关语、文化特定表达可能需要人工校对
- 代码块内字符串内容不自动翻译（需显式指定）
- 术语表未收录的术语选择最通用译法，可能存在争议
