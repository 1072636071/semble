# 真实凭据端到端冒烟

**Status:** ready-for-human

**Blocked by:** 04

**构建内容：** 用真实令牌在三个平台上各跑一次真实操作，确认技能在纸面之外真的能用：cnb、GitHub、Gitee 各自完成一次带凭据的远端操作（如 push 到私有仓库或调用一次需鉴权的 API）。此前的评测只验证"行为是否合规"，这一张验证"令牌是否真的有效、注入形态是否被平台接受"。需要人介入执行——agent 不应在无人监督下拿真实密钥跑远端写操作。

**验收标准：**

- [ ] cnb 平台一次带凭据远端操作成功，remote 中用户名位为 `cnb`
- [ ] GitHub 平台一次带凭据远端操作成功，令牌以认证头或环境变量方式注入均可
- [ ] Gitee 平台一次带凭据远端操作成功
- [ ] 三次操作中，终端回显、日志、会话记录里均**无令牌明文**（事后检索令牌特征串为零命中）
- [ ] 三次操作均未把带凭据的 remote 写回仓库配置（或操作后已清除）
- [ ] 任一平台失败时，能明确区分是"令牌失效/权限不足"还是"注入形态错误"，结论记录进本工单评论
