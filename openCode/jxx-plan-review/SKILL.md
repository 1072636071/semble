# 语义方案审查（门下省）

独立审阅已固化的 GOAL.md 契约，判断该方案是否值得进入执行循环。不审形式（否决门已审），审内容。

```
goal-contract（契约固化 + 否决门自检）→ plan-review（语义审查）→ goal-execute（执行循环）
                                           ↓ 封驳
                                        打回 goal-contract 修正
```

## Guidelines

- 前提：`.goals/{name}/GOAL.md` 已存在且已通过 goal-contract 的否决门（V1-V10）。若契约只有草稿未固化，先退回 goal-contract。plan-review 不修改 GOAL.md——只审不改，修正由 goal-contract 负责。
- 收集上下文：读取 `.goals/{name}/GOAL.md` 全文。若 PROGRESS.md 已存在同时读取。读取 `_index.md` 了解并行目标。不读取否决门自检日志、用户原始对话上下文、生成过程——这些会污染审查独立性。
- 逐维度审查（D1-D5），每个维度输出通过/问题，有问题的给出具体封驳理由。封驳时必须给出具体修正方向，而非"请重新设计"。
- 综合判定：全部通过 → 准奏（直接进入 goal-execute）；有建议无封驳 → 附条件准奏（进入执行但 PROGRESS.md 记录警告）；有封驳 → 封驳（列出所有封驳项打回 goal-contract）。
- 记录审查结果到 `.goals/{name}/REVIEW.md`。封驳时 REVIEW.md 的修正建议部分即为 goal-contract 的修正指引。
- 根据目标复杂度调整审查深度：深度调研/多人协作/高风险目标 → 全维度深审；单文件脚本/一次性工具 → D1+D4 即可。

## 审查维度

- **D1 覆盖完整性** — 契约是否覆盖目标所有关键维度，是否有遗漏的边界场景或无声明假设。审：Goal 范围边界是否清晰；Acceptance 是否覆盖所有关键交付物形态；有无关键用户流程或边界场景未被捕获；有无外部条件未写入 Constraints。封驳：明显遗漏的交付物形态；关键边界场景未覆盖；无声明假设且可能不成立。
- **D2 可行性** — 方案技术上是否可行，子任务拆解方向是否合理。审：交付物在当前技术栈下是否可实现；切片依赖顺序是否正确；关键路径是否有单点阻塞；是否有循环依赖。封驳：明确的技术不可行点；切片依赖顺序有逻辑错误；循环依赖或单点阻塞且无应对策略。
- **D3 约束一致性** — Constraints 内部是否矛盾，与 Goal 是否冲突。审：Constraints 之间是否互斥；是否与 Goal 冲突；保护性约束是否覆盖风险面；Budget 是否与复杂度匹配。封驳：Constraints 内部互斥；与 Goal 核心需求直接冲突；Budget 明显不匹配（差距 ≥ 一个数量级）。
- **D4 审计就绪性** — 契约是否具备进入执行循环的审计条件。审：每条 Acceptance 的验证命令是否真实可执行；输出是否可判定通过/失败；PauseConditions 是否覆盖高风险项（凭证/支付/生产数据/版权/发布）；是否过于宽泛导致频繁中断。封驳：验证命令无法执行；输出无明确通过/失败信号；高风险场景未在 PauseConditions 中；PauseConditions 过于宽泛。
- **D5 可恢复性** — 契约是否支持断点恢复。审：目标命名是否稳定；切片拆解是否足够细粒度；是否有明确的"最小可交付"。封驳：切片粒度过粗；目标名称包含动态部分。

## 异常处理

- GOAL.md 不存在 → 提示先运行 goal-contract。
- GOAL.md 未通过否决门 → 提示先完成否决门检查。
- PROGRESS.md 已存在且有执行记录 → 该目标已进入执行，审查无意义，直接放行。
- subagent 不可用 → 降级为"换视角自检"——抛开生成过程，以第三方姿态仅凭 GOAL.md 原文逐维度审查。

## 反模式

- 审形式不审内容——重复否决门的工作。否决门已审过，本技能审语义。
- 提模糊建议——"方案不够好"不如"D2：切片 2 依赖切片 3 的输出，但切片 3 声明依赖切片 2——循环依赖"。
- 过度审查——对低风险小目标逐维度深挖。
- 阻塞合理方案——吹毛求疵，对无伤大雅的细节封驳。建议（⚠️）和封驳（❌）的区分标准：是否会导致执行循环失败或交付物不可用。
- 泄露上下文——引用了 goal-contract 生成过程中的信息。只以 GOAL.md 原文为证据来源。
