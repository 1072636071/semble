# Wayfinder

一个松散的想法到来了——大到单个 agent 会话无法承载，且笼罩在迷雾中：从这里到目的地的路径尚不可见。寻路就是找到那条路径，而不是冲向目的地。此技能将路径绘制为 repo issue tracker 上的共享地图，然后逐一处理其工单，直到路径清晰。

目的地因工作而异，命名目的地是寻路的第一步——它塑造每个工单。它可能是一份交出去迭代的规格文档、一个在规划开始前锁定的决策、或一个就地完成的变更。地图是领域无关的。

## Guidelines

- Wayfinder 默认是规划：每个工单解决一个决策，地图在路径清晰时完成——在有人去做那件事之前，没有剩下需要决定的。想要直接动手的冲动通常是你到达地图边缘的信号，是时候交接了。产出决策，而非交付物。
- 按名称引用。在人阅读的所有内容中用名称引用工单，绝不用裸 id、编号或 slug。id 和 URL 嵌在名称之内，从不替代名称。
- 每次会话绝不超过一个工单。
- issue tracker 应已提供——如果没有，运行 `jxx-setup-matt-pocock-skills`。若没有提供 tracker，默认使用本地 markdown tracker。

## 地图

地图是 repo issue tracker 上的单个 issue，标记为 `wayfinder:map`。其工单是地图的子 issue。地图是一个索引，不是存储——它列出已做出的决策并指向持有其详情的工单；一个决策只存在于一个地方——它的工单——所以地图从不复述它，只做摘要并链接。

地图正文包含：目的地（到达此地图终点意味着什么）、备注（领域、每次会话应查阅的技能、固定偏好）、决策进展（每个已关闭工单一行摘要 + 链接）、尚未明确（迷雾）、超出范围。

## 工单

每个工单是地图的子 issue，带一个 `wayfinder:<type>` 标签。一个会话通过将工单分配给驱动地图的开发者来认领它。阻塞使用 tracker 的原生依赖关系——这很关键，因为它在 tracker UI 中可视化地渲染前沿。前沿是开放的、解除阻塞的、未认领的子工单。

工单类型（HITL = 人在回路中，AFK = agent 单独驱动）：

- **Research**（AFK）— 阅读文档、API 或本地资源，创建 markdown 摘要作为链接资产。
- **Prototype**（HITL）— 通过制作廉价、粗糙、具体的可反应工件提高讨论保真度，通过 `jxx-prototype` 技能。
- **Grilling**（HITL）— 通过 `jxx-grilling` 和 `jxx-domain-modeling` 技能进行的对话，一次问一个问题。默认情况。
- **Task**（HITL 或 AFK）— 必须在决策可以做出之前完成的手动工作。agent 在可能时单独驱动；否则给人类一个精确的检查清单。

## 战争迷雾

地图是刻意不完整的：不要绘制你还看不到的东西。活跃工单之外是战争迷雾——你能感觉到即将到来但还无法精确定位的决策和调查的模糊视图。解决一个工单会清除它前方的迷雾，将现在可 spec 化的内容毕业为新的工单——一次一个，直到通往目的地的路径清晰。

迷雾还是工单？测试标准是你现在能否精确陈述问题——不是你现在能否回答它。工单当问题已经明确；尚未明确当你还不能那么精确地表述它。

## 超出范围

目的地之外的工作是超出范围的——它不是迷雾，也不属于尚未明确。它在地图有自己的超出范围节。超出范围的工作永不毕业——前沿止于目的地。将某事排除在范围之外是范围界定行为，不是路径上的步骤。

## 调用

### 绘制地图

- 命名目的地。运行 `jxx-grilling` 和 `jxx-domain-modeling` 会话以确定此地图在寻找什么路径。
- 映射前沿。广度优先追问，浮现开放决策和现在可采取的第一步。若没有浮现迷雾——路径已清晰，不需要地图。
- 创建地图（标签 `wayfinder:map`）：目的地和备注填入，决策进展为空，迷雾草拟到尚未明确。
- 创建现在能 spec 化的工单作为地图的子 issue，然后在第二轮连接阻塞边。
- 停下——绘制地图是一个会话的工作；不要同时解决工单。

### 处理地图

- 加载地图——低分辨率视图，不是每个工单正文。
- 选择工单。若用户指定了使用它，否则取第一个前沿工单。认领它：在任何工作之前分配给自己。
- 解决它——按需缩放：按需获取任何相关或已关闭工单的完整正文；调用备注块中命名的技能。如果不确定，使用 `jxx-grilling` 和 `jxx-domain-modeling`。
- 记录解决方案：将答案作为解决评论发布，关闭 issue，向地图的决策进展追加上下文指针。
- 添加新浮现的工单（创建后连接）；毕业答案已使其可 spec 化的任何迷雾；若答案揭示工单位于目的地之外，将其排除在范围之外；若决策使地图其他部分失效，更新或删除那些工单。
