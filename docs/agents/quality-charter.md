# 质量宪章（Quality Charter）

**状态**：生效
**溯源**：`docs/memorial/003-ai-agent-maintainability/`（原始追问、实测数据、决策 ADR）

> **唯一权威源。** 各 skill / prompt / 规范**引用**本文件，**不复制内容**（与「风格宪章」同一纪律：单文件权威维护，避免多处漂移）。

## 为什么需要它

在「agent 执行、人兜底」的工作模式下，若所有质量判断的输入都是 agent 自己的话，会出现三个症状 —— 它们是**同一个病**：

| 症状 | 表现 |
|---|---|
| **没信号** | 改错了，没有任何命令能测出来 |
| **看不懂** | 一次改一大片，diff 无法核对 |
| **漏需求** | 验收框全部勾选，但框描述的要求实际没做到 |

**同一个病：把判断权交给了被判断者。**

## 信任模型（前提）

**人工不审核代码，不影响提交与合并**；`jxx-code-review` 的审查结论视为可信。人工只做**体验 / UI 验证**。

| 角色 | 职责 | 阻塞合并？ |
|---|---|---|
| 执行 agent（`jxx-implement`） | 改代码 + 附可复现证据 + 验收分流 | — |
| `jxx-code-review`（独立子 agent，标准轴 + spec 轴） | 复核**证据可复现性** + spec 覆盖 | **是** |
| 人工 | 体验 / UI 验证 | **否** |

**两条铁律由此而来**：

1. **复核者必须自己取证。** 人工既不看代码，`jxx-code-review` 的失误就**没有任何下游兜底** —— 它是**系统单点** ⇒ 它**必须自己执行命令 / 测试**来核对证据，**不得采信执行者提供的证据文本**。
2. **找不到 spec 必须标「未审」，不得静默通过。** spec 轴被跳过时，「漏需求」检测会消失 —— 那是**假绿灯**。

## 五条宪章

### 一 · 证据优先

**凡质量结论，必须附可被独立复核的证据。执行者自述不构成证据。**

推论：验收框的 `- [x]` 不是结论；「我做完了」不是证据；取证与复核必须由**非执行者**的独立主体完成。

### 二 · 验收框二选一

每条验收标准必须二选一，**不允许「勾了完事」这第三种状态**：

- **机器可验** ⇒ 附**可复现证据**：用例名（可被 grep 到）/ 命令（`exit 0`）/ 文件:行
- **机器不可验** ⇒ 进**人工验证清单**

验收点的**格式、覆盖清单、禁词与判定口径**不在此复述——唯一权威源是 `jxx-to-tickets` 技能的 `references/acceptance-criteria.md`（随技能分发，目标仓库同样可达）。本节只定义「二选一」这条原则。

### 三 · 验证职责分界

**判据 = 「这个验收点能不能写成一条程序断言？」**

| 维度 | 归属 |
|---|---|
| 功能是否存在 / 是否能用 | **AI / 机器** |
| 是否好用 / 体验是否舒适 | **人** |
| UI 交互 | **人** |

**举证责任在 agent**：默认必须给机器验证；只有当能说明「此点无法程序断言」时才允许进人工清单。（防逃逸）

### 四 · 人工验证清单显式化

不可机器验证的项必须落成**可勾选条目**，双落点：

- **本地**：`.scratch/<NN>-<feature>/HUMAN-CHECK.md` —— **不得放 `.temp/`**（被 gitignore 且语义是临时；此清单需留存、跨会话）。
- **线上**：若项目具备任务通道，新增一条任务；**按工单聚合**，避免刷屏。

**条目字段**：验证点 · 操作步骤 · 预期结果 · 未验证的后果 · 由哪条验收框降级而来。

**不阻塞关单**：清单只需**存在且条目完整**，**允许长期未勾选** —— 它是「待人工体验的待办」，不是合并条件（见「信任模型」）。

### 五 · 禁止放宽标准换绿灯

不得以「改类型定义 / 放宽断言 / 加豁免 / 加 `!`」使验收通过。

放宽会把真问题一起放行，**并成为后续所有 agent 的默认行为模板** —— 这是最难逆转的损害。修不动的项，宁可显式记入缺口，也不许改判据。

## 尺度：从轻

实现本宪章的机制必须**从轻**：单脚本 + grep 能落地的不上两层架构；不引入新框架、新服务。

人的注意力应被引导到真正需要判断的地方（**好不好用**），而不是被消耗在机器本该测的事情上（**有没有这个功能**）。

## 与其他规范的关系

- 与 `docs/agents/issue-tracker.md` 的 `done` 条件配套 —— 该文件的关单条件应包含：证据可复现、无未勾选的人工验证项。
- 与「风格宪章」平级、互补：**风格宪章管「怎么写」，本宪章管「怎么算做完」。**
