lean-ctx（LeanCTX）

LeanCTX（Lean Context）是一个本地优先、模型无关的 AI 编码代理上下文运行时（定位语：Control what your AI can see）。它并行于你的编码代理运行，在「读取路径」上通过 MCP 工具与 Shell Hook 压缩/缓存上下文，在「传输路径」上可选通过本地代理压缩每一次模型请求；并承担理解任务、路由正确上下文、压缩发送内容、追踪成本与结果五大职责，适合中大型仓库、频繁切换项目、多任务并行的开发者。

简介

本地优先的 AI 编码代理上下文运行时：压缩/缓存/路由上下文，并追踪 token 成本与结果（Control what your AI can see）。

核心特性

  • 上下文压缩：10 种文件读取模式（full / map / signatures / diff / lines:N-M / density:X …），缓存重读仅 ~13 tokens；Shell 输出 95+ 压缩模板覆盖 git/npm/cargo/docker/kubectl/terraform（270 条直通规则）；Tree-sitter AST 支持 27 种语言；压缩可逆（CCR，剪枝内容进内容寻址存储，可 ctx_expand 恢复）
  • 智能分诊：ModePredictor 按文件类型学习最优读取模式；IntentEngine 对查询复杂度分类，简单查询低成本
  • 知识路由：会话记忆（CCP）跨聊天持久化任务/事实/决策；知识图谱（时间事实/情景/程序记忆）；属性图（imports/calls/exports/type_ref）；可导出 .ctxpkg 便携包
  • AI 价值网关：浏览器实时 token/压缩仪表盘；按角色/代理预算与节流；Context Proof（ctx_proof/ctx_verify 四层验证 + CI 漂移门）
  • 影子推荐：Shadow Mode 对比基线，给出成本/CPAO/质量报告与节省建议
  • 双平面架构：读取路径（MCP 工具 + Shell Hook）负责压缩与缓存；传输路径（可选本地代理）压缩每一次请求，prompt-cache 安全且可固定推理强度

集成方式

Shell Hook（读取路径）透明压缩 git/npm/cargo/docker 等常见命令输出，LLM 看到更少噪声；lean-ctx -c "git status" 压缩执行，--raw 可绕过
MCP Server（读取路径）标准 MCP 协议暴露 ctx_* 工具族（读取/缓存/增量/搜索/记忆/多代理/重构/验证等），如 ctx_url_read、ctx_refactor、ctx_agent、ctx_handoff、ctx_expand、ctx_retrieve、ctx_proof、ctx_verify、ctx_knowledge、ctx_callgraph
Proxy 代理（传输路径，可选）lean-ctx proxy enable 本地代理压缩每次请求（prompt-cache 安全），可固定推理强度 proxy.effort；Claude Pro/Max 因 OAuth 不重定向，仅启用 ctx_* 工具
配置全局 ~/.config/lean-ctx/config.toml；项目根 .lean-ctx.toml 自动合并覆盖；Docker 场景用 .lean-ctx-id 区分唯一名
一键接入lean-ctx init --agent <name>（支持 Cursor/Claude Code/Codex/Gemini/Windsurf/Copilot/Neovim/Emacs/Zed/CodeBuddy 等 30+ 代理）/ lean-ctx onboard / lean-ctx setup

使用

文件智能读取（10 种模式）bash
# 读取模式：full / map / signatures / diff / lines:N-M / density:X
lean-ctx read src/server.rs -m map          # API 表面映射（压缩 ~98%）
lean-ctx read src/server.rs -m signatures   # AST 签名 + 行跨度
lean-ctx read src/server.rs -m diff         # 差异视图
lean-ctx read src/server.rs -m density:0.4  # 保留高熵行至 ~40% token
lean-ctx read src/server.rs -m lines:100-200 # JIT 按需展开
# 已缓存文件重读仅需 ~13 tokens
Shell 输出压缩bash
lean-ctx -c "git status"     # 透明压缩命令输出后喂给 LLM
lean-ctx -c --raw "git status" # 单条命令跳过压缩
一键包装代理（wrap）bash
lean-ctx wrap cursor     # 为某代理配置代理重定向 + ctx_* 工具
lean-ctx wrap claude     # Claude Code 仅启用 ctx_* 工具（无 OAuth 重定向）
lean-ctx unwrap cursor   # 撤销
知识 / 调用图bash
lean-ctx overview                       # 会话/知识总览
lean-ctx knowledge recall "auth"          # 召回相关知识
lean-ctx knowledge consolidate --all      # 合并会话记忆
lean-ctx graph impact src/auth.rs         # 影响面分析
lean-ctx smells scan                       # 代码异味扫描
成本与洞察bash
lean-ctx savings --period week              # 审计账本：本周节省
lean-ctx value-report --format markdown --last 20
lean-ctx shadow --latest                   # 影子模式对比报告
lean-ctx gain --live                       # 实时增益
lean-ctx dashboard                         # 浏览器仪表盘
lean-ctx watch                             # TUI 监控
上下文工程 / 打包 / 代理bash
lean-ctx plan "refactor billing" --budget 8000   # 预算内规划
lean-ctx compile --mode balanced
lean-ctx pack --pr                                 # 打包为 PR 上下文
lean-ctx snapshot create|list|show|verify|restore|publish|import
lean-ctx proxy enable                             # 传输路径压缩
lean-ctx serve --root ./api --root ./web          # 多仓库 HTTP MCP
lean-ctx team serve --config team.toml
诊断与生命周期bash
lean-ctx doctor                 # 自检
lean-ctx doctor --fix           # 自动修复
lean-ctx doctor overhead --gate # 开销门禁
lean-ctx-off                    # 当前 shell 临时禁用
lean-ctx uninstall --dry-run    # 卸载预览

备注

  • 版本：当前最新 v3.10.1（2025-09 发布）；升级用 lean-ctx update（自动刷新 shell hooks），或 cargo/npm/brew 升级后跑 lean-ctx setup 刷新别名
  • 本地优先、零遥测、模型无关：并行于 Cursor/Claude Code/Copilot/Codex/Gemini 等 30+ 代理运行；首次用 lean-ctx init --agent <name> 或 lean-ctx onboard 接入
  • 收益取决于三要素：reach（命令覆盖）、context lifetime（缓存复用）、provider pricing；微小仓库、需原始日志、无 shell 调用的场景收益有限
  • Shell Hook 行为可用配置控制：shell_activation = "agents-only" 仅在 AI 会话激活；单条命令加 --raw 跳过压缩
  • 扩展机制 Addons：签名 WASM 模块（SHA-256 校验），本地文件安装、无市场；输出默认标记 untrusted 并洗脱密钥
  • 配置层级：全局 ~/.config/lean-ctx/config.toml，项目根 .lean-ctx.toml 自动合并（Docker 用 .lean-ctx-id 区分唯一名）；可用 LEAN_CTX_NO_UPDATE_CHECK=1 关闭更新检查
