jxx-skill-init👤 用户true本仓库新建技能：ship init 模板 + 桶选择 + frontmatter 规范，一次过 check 门禁。
impeccable🤖 模型前端界面设计/审查/打磨（工艺级视觉与 UX）；hook runner 待对齐四厂商。
