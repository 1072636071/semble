简介

面向 AI 编码代理的上下文窗口优化 MCP 服务：把工具原始输出留在本地沙箱、只回传计算结果，实测 315 KB → 5.4 KB（降 98%），并跨会话压缩持久化记忆，强制「用代码思考」范式。

核心特性

  • 上下文节省（Context Saving）：通过沙箱工具把原始数据挡在上下文窗口之外。官方实测一次 30 分钟复杂重构任务，315 KB 原始输出压缩到 5.4 KB，减少约 98%——原本二三十分钟就「失忆」的 Agent 可稳定工作更久
  • 会话连续性（Session Continuity）：每次文件编辑、git 操作、任务、错误、用户决策都记录在 SQLite；当会话触发 compact 压缩时，context-mode 不把数据倒回上下文，而是索引进 FTS5 全文索引、按 BM25 检索只回传相关内容——模型无缝接上之前进度。若未 --continue，上次会话数据立即删除，保证干净起点
  • 用代码思考（Think in Code）：把 LLM 当代码生成器而非数据处理器。与其把 50 个文件读进上下文计数，不如写脚本计数后只 console.log 结果——一个脚本替代十余次工具调用、省约 100x 上下文（实测 47 次 Read=700 KB → 1 次 ctx_execute=3.6 KB）。这是全部 17 个受支持客户端的强制范式
  • 路由强制（Routing Enforcement）：通过 PreToolUse / PostToolUse / UserPromptSubmit / PreCompact / SessionStart / Stop 等 hook + 11 个 ctx_* MCP 工具，把裸 curl、大文件读取等低效/危险调用重定向到沙箱内处理。不做强制的散文风格约束（路由块只管数据去处，不管模型怎么说话）

集成方式

Claude Code（全自动）插件市场接入：/plugin marketplace add mksglu/context-mode；/plugin install context-mode@context-mode；重启后 /context-mode:ctx-doctor 校验。SessionStart hook 在运行时注入路由指令，不写项目文件；注册全部 hooks 与 11 个 MCP 工具
11 个 ctx_* MCP 工具6 个沙箱工具：ctx_batch_execute、ctx_execute、ctx_execute_file、ctx_index、ctx_search、ctx_fetch_and_index；5 个元工具：ctx_stats、ctx_doctor、ctx_upgrade、ctx_purge、ctx_insight
适配 17+ 平台Claude Code、Codex、Cursor、Gemini CLI、JetBrains Copilot、Kilo、Kiro、OMP、OpenClaw、OpenCode、Pi、Qwen Code、VS Code Copilot、Zed、Antigravity IDE、Antigravity CLI (agy)、GitHub Copilot CLI、Kimi Code。有 hook 能力的平台自动强制路由，无 hook 平台需一次性复制路由文件
安装基底npm install -g context-mode 为通用基底；各平台通过对应插件机制接入（Claude Code 插件市场 / Antigravity agy plugin / Copilot CLI plugin / OpenClaw 脚本等）

通用安装（npm 全局）bash
# 安装 CLI 与 MCP server 基底
npm install -g context-mode

# 随后在目标平台用平台对应的插件机制接入（见下）
Claude Code（插件市场，全自动）bash

/plugin install context-mode@context-mode
# 重启 Claude Code（或 /reload-plugins）
/context-mode:ctx-doctor   # 全部 [x] 即正常（校验运行时/hooks/FTS5/插件注册）

使用

用代码思考：脚本处理数据，只回传结果javascript
// 之前：47 × Read() = 700 KB
// 之后：1 × ctx_execute() = 3.6 KB
ctx_execute("javascript", `
  const files = fs.readdirSync('src').filter(f => f.endsWith('.ts'));
  files.forEach(f => console.log(f + ' ' +
    fs.readFileSync('src/' + f, 'utf8').split('\n').length + ' lines'));
`);
ctx_stats — 查看上下文节省bash
# 每工具分解、token 消耗、节省比
ctx stats
# 非 Claude Code 平台直接在聊天输入 ctx stats，模型自动调用 MCP 工具
ctx_doctor — 诊断环境bash
ctx doctor   # 校验运行时、hooks、FTS5、插件注册、版本
ctx_index / ctx_search — 持久化知识库bash
ctx index ./src            # 索引本地目录进 FTS5 知识库
ctx search "auth middleware"  # 压缩后续接时按 BM25 检索相关片段
ctx_upgrade / ctx_purge / ctx_insightbash
ctx upgrade   # 拉取最新、重建、迁移缓存、修复 hooks
ctx purge    # 永久删除知识库索引内容
ctx insight  # 打开托管 Insight 仪表盘（context-mode.com/insight），组织级 AI 工程分析
