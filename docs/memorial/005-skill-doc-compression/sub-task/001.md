# 调查工单 001：面向 AI 阅读的文档极限压缩方式调研（memorial 005）

## 任务描述
为「jxx 技能文档压缩归档技能」的选型提供依据：调研 2025-2026 业界在"把文档尽可能压缩、同时 AI/LLM 阅读时不丢失关键内容"方面的方法、工具与格式。

## 明确问题
1. 经过验证的 LLM 上下文/文档压缩技术有哪些（LLMLingua 系列、RAPTOR 层级摘要、结构化大纲、语义压缩等）？各自压缩率与信息保真度的公开数据？
2. 可直接压缩 markdown 的现成工具有哪些？提示：本仓库 docs/guide/ 已有 lean-ctx、headroom、rtk、code2prompt 的工具档案，优先读这四个。
3. "不丢内容"的实践共识：什么信息绝不能压（决策、数字、代码、引用、原话）？什么可以安全压（客套、重复、过程叙述）？
4. 归档后供 AI 检索/续读的场景，业界推荐什么组织格式（llms.txt、MOC/索引页、层级摘要、frontmatter 元数据）？
5. 是否存在"压缩-还原"（rehydrate）模式：存压缩版 + 保留可展开原文的引用结构？有哪些实现？

## 期望产出
每个问题：结论 + 关键数据/引用 + 来源 URL。文末给「本项目可用方案候选清单」（按压缩率 × 保真度 × 落地成本排序）。
