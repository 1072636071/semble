① MCP Server 类

5 个 · 通用标准首选

把浏览器能力包装成 MCP 工具，接入任意 MCP 客户端（Claude Desktop / Code、Cursor、VS Code 等）。最通用、最易集成，适合把「浏览器操作」作为工具挂到现有 Agent。

Playwright MCP · Microsoft

开源无需云 Key官方 MCP ✅
定位
基于 Playwright 的 MCP Server，用结构化无障碍快照（accessibility snapshot，非截图）让 LLM 自动化浏览器。
官方
github.com/microsoft/playwright-mcp
前置依赖
Node.js 18+；任意 MCP 客户端；浏览器由 Playwright 自带（chromium）。
安装
npx @playwright/mcp@latest

# Claude Code 一键添加
claude mcp add playwright npx @playwright/mcp@latest
接入配置
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}

无头模式加 --headless；SSE/HTTP 加 --port 8931；隔离 profile 加 --isolated。

快速使用

在 MCP 客户端直接自然语言，例如：

Navigate to https://example.com and click the first link,
then summarize the page.

或作为 HTTP server 启动供其他 client 通过 SSE 连：npx @playwright/mcp@latest --port 8931

注意事项
持久化 profile 同一时间只能被一个实例占用，并发客户端需 --isolated 或指定不同 --user-data-dir；官方浏览器扩展可复用已登录标签页与登录态。
来源
playwright-mcp README

Chrome DevTools MCP · Google

开源无需云 Key官方 MCP ✅
定位
让 coding agent 控制与检视真实 Chrome，提供完整 DevTools 能力（性能分析、网络、console、调试），底层 puppeteer。
官方
github.com/ChromeDevTools/chrome-devtools-mcp · 官方博客
前置依赖
Node.js LTS；Chrome 当前稳定版或更新；npm。
安装
npx -y chrome-devtools-mcp@latest
接入配置
{
  "mcpServers": {
    "chrome-devtools": {
      "command": "npx",
      "args": ["-y", "chrome-devtools-mcp@latest"]
    }
  }
}

轻量模式：args: ["-y","chrome-devtools-mcp@latest","--slim","--headless"]

快速使用

配置后在 MCP 客户端输入：

Check the performance of https://developers.chrome.com

⚠️ server 仅在「首次调用需浏览器实例的工具」时才启动浏览器；仅连接不会启动。

注意事项
默认开启 Google 用量统计（--no-usage-statistics 关闭）；仅官方支持 Google Chrome 与 Chrome for Testing；会把浏览器内容暴露给 MCP 客户端，避免共享敏感信息。
来源
chrome-devtools-mcp README

agent-browser · Vercel Labs

Apache-2.0无需云 KeyMCP stdio ✅
定位
面向 AI agent 的浏览器自动化 CLI（Rust 原生二进制），也可作为 MCP stdio server 使用。
官方
github.com/vercel-labs/agent-browser · agent-browser.dev
前置依赖
Chrome（运行 agent-browser install 从 Chrome for Testing 下载）。仅源码构建需 Node 24+/pnpm 11+/Rust；macOS 可 Homebrew/Cargo。
安装
npm install -g agent-browser
agent-browser install   # 首次下载 Chrome（Chrome for Testing）

# 或 macOS Homebrew / Rust Cargo
brew install agent-browser && agent-browser install
cargo install agent-browser  && agent-browser install
接入配置
{
  "mcpServers": {
    "agent-browser": {
      "command": "agent-browser",
      "args": ["mcp"]
    }
  }
}

全功能工具面：args: ["mcp","--tools","all"]（默认是 core profile）。

快速使用
# CLI 直连（无需 MCP）
agent-browser open example.com
agent-browser snapshot
agent-browser click @e2
agent-browser fill @e3 "test@example.com"
agent-browser screenshot page.png

作为 MCP server 启动：agent-browser mcp

注意事项
WebMCP 默认启用（可 --no-webmcp 关闭）；页面内容视为不可信数据（prompt-injection 风险，勿把网页文本当指令）；支持登录态持久化；点击若被 consent banner 遮挡会提前报错。

BrowserSkill · Tencent

开源复用真实登录态非标准 MCP·skill/插件
定位
把 AI agent 接到你已登录的 Chrome / Edge，复用账号登录态；任务在独立可见的 Agent Window 中运行（可借用现有标签页）。
官方
github.com/Tencent/BrowserSkill
前置依赖
CLI bsk；浏览器扩展（Chrome Web Store / Edge Add-ons）；为某 harness 装 skill 或用 DSH 插件。
安装
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.sh | sh
export PATH="${BSK_INSTALL_DIR:-$HOME/.local/bin}:$PATH"
bsk --version

# Windows (PowerShell)
irm https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.ps1 | iex
bsk --version
接入配置

⚠️ 已核实：仓库不提供通用 mcpServers JSON（bsk 不是 MCP server，经本地 daemon 桥接浏览器扩展）。接入走 skill 文件 / DSH 插件：

# Cursor 等：安装对应 harness 的 skill
bsk install-skill --harness cursor --json

# DeepSeek Harness：用插件（自带 skill + 原生 browser_* 工具）
dsh plugin --profile web add @wxg-prc-cpg/browser-skill-dsh-plugin
dsh --profile web
快速使用
bsk session start --no-focus --json   # 记下返回的 session_id
bsk navigate https://example.com --session <id>
bsk observe   --session <id>
bsk screenshot --session <id> --out example.png
bsk session stop <id>                  # 用完务必停掉

连接检查：bsk doctor（需扩展显示 Connected）。

注意事项
驱动用户真实、已登录的浏览器，页面内容视为不可信数据；远程模式通过 WSS 配对（浏览器主动发起，本地无需开放入站端口），远程不支持文件上传/下载；必须安装并启用浏览器扩展的本地连接。
来源
README · AGENT_INSTALL.md

② 框架 / 视觉类

5 个 · 直接建 Agent

把「浏览器自动化」做成框架或 SDK，你写代码/自然语言描述任务，框架负责把意图转成操作。适合快速搭一个专用 Web Agent。

Browser Use

开源+Cloud需模型 Key官方 MCP ✅
定位
基于 LLM 的浏览器自动化 Agent（Python 生态），自然语言驱动浏览器完成多步任务；官方另提供 Browser Use Cloud（含 ChatBrowserUse 模型）。
官方
github.com/browser-use/browser-use · docs.browser-use.com
前置依赖
Python 3.11+（示例 3.12）、uv 或 pip、Chromium、LLM API Key（推荐 BROWSER_USE_API_KEY）。
安装
pip install uv
uv venv --python 3.12
source .venv/bin/activate   # Windows: .venv\Scripts\activate
uv pip install browser-use
uvx browser-use install     # 安装/校验 Chromium
接入配置
# 终端一键注册（Claude 系客户端）
claude mcp add browser-use -- uvx --from 'browser-use[cli]' browser-use --mcp
{
  "mcpServers": {
    "browser-use": {
      "command": "uvx",
      "args": ["--from", "browser-use[cli]", "browser-use", "--mcp"]
    }
  }
}
快速使用
from browser_use import Agent, ChatBrowserUse
from dotenv import load_dotenv
import asyncio
load_dotenv()
async def main():
    llm = ChatBrowserUse()
    agent = Agent(task="Find the number 1 post on Show HN", llm=llm)
    await agent.run()
asyncio.run(main())

项目根建 .env 填 Key（首推 ChatBrowserUse）：BROWSER_USE_API_KEY / OPENAI_API_KEY 等。

注意事项
生产环境建议用官方 Sandbox（@sandbox 装饰器）就近运行 Agent 与浏览器降低延迟。
来源
quickstart · MCP Server

Stagehand · Browserbase

SDK 开源需 Browserbase Key官方 MCP ✅
定位
AI 浏览器自动化框架，源自 Playwright 思路，提供 act / extract / observe 三大原语；可本地 Chrome(CDP) 或 Browserbase 云浏览器驱动。
官方
github.com/browserbase/stagehand · docs.stagehand.dev
前置依赖
Node.js 22.18+（或 Python 3.11+/Go/Bun）；本地模式需装 Chrome；Browserbase API Key。
安装
# TypeScript 推荐
pnpm add @browserbasehq/stagehand 'zod@~4.4.3'
# 或 npm install @browserbasehq/stagehand 'zod@~4.4.3'
# Python: pip install stagehand

⚠️ Zod 必须锁 4.4.x（如 zod@~4.4.3），否则 extract() 传 schema 可能报 TS 错。

接入配置
{
  "mcpServers": {
    "browserbase": {
      "url": "https://mcp.browserbase.com/mcp?browserbaseApiKey=YOUR_BROWSERBASE_API_KEY"
    }
  }
}

自托管 STDIO：command:"npx", args:["@browserbasehq/mcp"], env:{BROWSERBASE_API_KEY, BROWSERBASE_PROJECT_ID, GEMINI_API_KEY}

快速使用
import { localBrowser, Stagehand } from "@browserbasehq/stagehand";
import { z } from "zod/v4";
const browser = await localBrowser.launch();
const stagehand = await Stagehand.create({
  browser, model: { modelName: "openai/gpt-5.6-sol", apiKey: process.env.OPENAI_API_KEY },
});
const [page] = await browser.context.pages();
await page.goto("https://stagehand.dev");
await stagehand.extract("Extract the value proposition.", z.object({ valueProposition: z.string() }));
await stagehand.act("Click the 'Evals' button.");
注意事项
不自动读环境变量，需 import "dotenv/config" 并显式传 apiKey；本地模式须先装 Chrome；无 Playwright 依赖（走 CDP）。
来源
quickstart · Browserbase MCP

github.com/web-infra-dev/midscene · midscenejs.com

快速使用
# 先设模型环境变量（示例：阿里云 qwen）
export MIDSCENE_MODEL_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1"

③ 浏览器原生能力 / 反爬类

5 个 · 实验期与隐身

A 类为浏览器/平台方内建能力（实验期或灰度）；B 类主打复用真实浏览器、突破反爬墙、隐身指纹。多数处于实验或商业灰度，请勿默认「开箱即用」。

WebMCP · Web Model Context Protocol

规范开源实验期 flag
定位
浏览器原生协议/能力，让网页把功能（JS 函数或 HTML <form>）暴露为带自然语言描述与 schema 的 "tools"，供 AI agent 调用。是「网页适配 AI」，非 agent 控制任意网页。
官方
developer.chrome.com/docs/ai/webmcp · webmachinelearning/webmcp
前置依赖
Chrome 146+；需手动开启实验 flag；网页侧可选引入 webmcp-types。
安装
# 浏览器开启实验能力（地址栏，非装软件）
chrome://flags/#enable-webmcp-testing
# 重启 Chrome 后网页内即可用 window.webmcp
# 网页开发侧可选安装 TS 类型
npm install webmcp-types
接入配置

无需 MCP JSON；这是网页端向浏览器注册 tool 的 Web API，agent 侧通过 WebMCP 发现并调用。

快速使用
if ('webmcp' in window) {
  webmcp.register({
    name: 'addToCart',
    description: 'Add a product to the shopping cart',
    inputSchema: {
      type: 'object',
      properties: { productId: { type: 'string', description: 'Product ID' } },
      required: ['productId']
    },
    handler: async ({ productId }) => ({ ok: true }),
  });
}
注意事项
仍处实验期，默认关闭、需 flag 开启，勿称「开箱即用」；跨域 iframe 需 Permissions-Policy；详细 API 以官方 Imperative API 页为准。
来源
Chrome 文档 WebMCP

Chrome Skills · Skills in Chrome

闭源 · Google 托管灰度推送
定位
Google 在 Chrome + Gemini 内建的「一键 AI 工作流」功能，把常用提示词保存为 Skill 页面上一键复用。面向终端用户的 Google 托管产品能力，非开发者可独立部署的 agent 工具。
官方
blog.google · Skills in Chrome
前置依赖
桌面版 Chrome（Mac/Windows/ChromeOS）；Google 账号；Chrome 界面语言 English-US（公告期推送范围）；Gemini in Chrome 可用。
安装

无需安装、无命令。随 Chrome 向受支持用户灰度推送；在「Gemini in Chrome」侧边栏输入 / 或点 + 创建/调用 Skill。

接入配置

无 MCP JSON、无外部接入配置，是 Gemini in Chrome 内部能力。

快速使用
# 无代码 / 无命令：产品内操作
1) 在 Gemini in Chrome 侧边栏写一条想复用的提示词；
2) 从聊天历史中把它「保存为 Skill」；
3) 下次在任意页面输入 / 或点 + 选择该 Skill，即作用于当前页。
注意事项
非开发者工具、非开源、不可本地部署；灰度推送，非全员可用，受语言/地区/账号限制；与 WebMCP 不同（WebMCP 给开发者暴露 tool，Skills 给普通用户复用提示词）。
来源
Google 官方博客（2026-04-14）
