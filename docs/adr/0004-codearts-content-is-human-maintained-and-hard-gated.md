# ADR 0004：CodeArts 专属内容人工维护、缺失即硬门禁

- 日期：2026-08-12
- 状态：已接受

## 上下文

`SKILL-METADATA-MAPPING.md` §4 决定：源文件 `description` 按指针规则精剪，CodeArts 派生版改写为 5 行编号列表。但精剪自由文本**无法机械改写**为合格的 5 行列表（价值主张、触发词、前置条件等语义槽位需人判断），§5 也已否定脚本自动翻译（质量不可控）。

派生时若源文件缺少 CodeArts 所需英文内容（英文 description 块、`<!--en-->` 正文块），可选行为：

1. **硬门禁**（本决策）：该校验失败 → 该平台跳过安装 + 打印结构化错误（文件、缺失字段），ship 以非零退出码结束。
2. 软降级：缺失时该技能对 CodeArts 走原样复制 fallback——等于静默放弃规范要求，质量门禁形同虚设。
3. 自动补全：脚本占位生成或调用翻译——被 §5 明确否决。

## 决策

CodeArts 专属内容（`x-vendors.codearts.description-en` 5 行块、`<!--en-->` 正文块）由源文件人工维护；派生校验发现缺失即跳过该厂商安装并报错，ship 非零退出（对接 HARNESS-SPEC §2.2/§3.3 反馈契约）。其余厂商不受影响，正常安装。

## 后果

- 未准备英文内容的技能不会被静默塞进 CodeArts，失败信号即时可见。
- 双模式迁移（ADR 0002）下老技能走原样复制不受影响；只有迁入 src 形态的技能才受此门禁约束——迁移一个，补一个的英文块，工作量随迁移摊平。
- `ship check` 子命令复用同一校验逻辑，可在不安装的情况下预检全部技能的门禁通过情况。
