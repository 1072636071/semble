# ADR 0005: SEO 技能族仅项目级分发，路由技能兼任安装器

状态：已接受（2026-08-25）
来源：memorial 001-seo-geo-skill-templates / adr/0001

## 背景

本仓库既有分发模式是 ship 将技能安装到各厂商**用户级**目录（默认），项目级为 `--project` 选项。新 SEO/GEO 技能族（审查模板、写作模板、五件套、路由器）打破了这一默认。

## 决策

1. 整套 SEO 技能族**只存在于项目级**，无任何用户级全局安装。
2. 首次 bootstrap 由 `ship --project` 哑拷贝完成；`x-install` 增加 `project` 取值表达"仅项目级"。
3. 进场后的参数化生成、升级、缺失修复由项目内 `seo-router` 技能兼任，**不做独立安装脚本**。

## 为什么

- 五件套基本能力在各项目中被参数化子技能引用，全局安装无法保证版本与项目匹配；项目级自包含消除"少装一个就断链"。
- 项目级隔离使名字污染问题不存在，子技能得以用固定名（`seo-geo-audit` / `blog-writer`），升级路由逻辑可写死。
- 用户明确否决独立安装脚本，接受"安装逻辑写在技能提示词中确定性较差"的取舍。

## 被否决的替代方案

- **独立脚本 `install-seo-suite.mjs`**：确定性最强但收益不足以抵消维护成本。
- **用户级装一份 router 做种子**：与"无任何全局安装"冲突，且 router 需内置全家拷贝或回仓库取货，实现最复杂。
- **纯手动复制**：把 7 家厂商 × 两级目录的路径知识转嫁用户，违背分发知识收口原则。

## 影响

- ship 需支持 `x-install: project`（小改动）。
- `vendors.json` managedPrefixes 增加 `seo-`，残留清理覆盖该族。
- 未来若有第二个"项目级限定"技能族，此 ADR 为先例。
