# 阶段边界

一个**阶段**是会话内的一块工作——访谈、实现、QA。这个定义故意模糊：一个阶段在你认为*"好了，我们做完了"*时结束。

**阶段边界**是两个阶段之间的间隙，也是这个决策唯一归属的地方。阶段中途没有任何决策要做——继续，或者把剩余的工作拆成子 agent。在阶段中途压缩会让 agent 丢失线索。

## 五个选项

| 选项       | 它做什么                                                            |
| ---------- | ------------------------------------------------------------------- |
| **继续**   | 留在会话中。完全没有上下文切换。                                      |
| **`/clear`** | 清空上下文窗口，从零开始。                                           |
| **`/handoff`** | 写一个可移植的 markdown 文件，并在任何地方用它播种一个新会话。       |
| **子 agent** | 把任务送到它自己的上下文窗口，拿回一份报告。                          |
| **`/compact`** | 压缩这个上下文，并用摘要播种一个新会话。                            |

## 决策树

在边界处从上到下工作。第一个**是**获胜。

**1. 你能在这个会话中继续吗？** 有两件事让答案变为是：下一个阶段需要这个阶段作为**首要来源**，或者你有足够的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone) 剩余（约 150k token）容纳下一个阶段。访谈 → 实现是标准的是：实现想要逐字的推理，而不是它的摘要。继续不花钱也不丢东西，所以在考虑任何其他选项之前先排除它。

**2. 上下文与接下来要做的事无关吗？** 会话中的一切——探索、决策、死胡同——都是可丢弃的吗？如果是，**`/clear`**。它是棋盘上最便宜的走法：不花时间，交还整个窗口。`/clear` 也不是终结性的——旧会话保持可恢复。

弄错这个的成本是单向的。清除一个*相关*的上下文，你会失去你构建的东西背后的**为什么**，读回多少 diff 都无法找回。

**3. 你需要交接吗？** `/handoff` 范围很窄。只有当你处于以下情况时才需要它：

- 换到一个**新 harness**（Claude → Codex），
- 移到一个**新目录**或仓库，
- 把工作交给**同事**，
- 或者在**阶段中途**分叉一个附带任务，而不打乱你正在做的事情。

那个列表就是整个条款。`/handoff` 买到的是**可移植性**——一份可以旅行的文件。如果没有东西在旅行，你就不需要它。

**4. 这个任务能 AFK 完成吗？** 它的范围足够紧密，可以在你离开键盘时运行、无需引导吗？那就把它交给一个**子 agent**，让这个会话保持不动。自动化审查是标准场景：agent 读 diff 并报告，而它做的时候不需要你。

**5. 否则，`/compact`。** 相关上下文、相同 harness、相同目录，而你需要留在环里——这就是决策树落点，而且它经常落在这里。给它一条指令（`/compact 我们要 QA 这个区域`），这样摘要能保留下一个阶段需要的东西。

`/compact` 是**默认，而不是首选**。它位于底部，因为上面四个问题都比它更便宜或更精确。人们从这里开始的失败模式是：一个新会话对一个被摘要压平的决策充满自信地弄错。

## 首要来源与次要来源

除了**继续**之外的每个动作，都把**首要来源**变成**次要来源**——按它发生的样子存在的会话，被一个它的摘要替代。这种交换总是同样的形状：

| 来源                            | 信息 | 噪音 | 活动空间 |
| ------------------------------- | ----- | ----- | -------- |
| 首要（继续）                    | 完整  | 很多  | 很小     |
| 次要（`/compact`、`/handoff`）   | 有损  | 更少  | 很大     |

这就是为什么问题 1 放在第一位。只有当留下比保存更贵时，你才付出有损性。

## 这些是判断调用

这些问题不是客观的——每个都包含品味，同一个边界可以在两天里走向两个方向。价值在于**按顺序**询问它们，在边界处而不是在工作的中途。
