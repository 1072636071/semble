## 它做什么

`wizard` 生成一个交互式 bash 脚本，逐步引导人类完成一个手动流程——接入第三方服务、运行一次性迁移、把项目从状态 A 移到状态 B。它打开每个 URL、说明要点击和复制什么、捕获返回的值，并把它们写入 `.env` 文件和 GitHub Actions 机密。

[agent](https://www.aihero.dev/ai-coding-dictionary/agent) 写这个脚本；它从不运行它。你自己、在你自己的机器上运行。所以向导不是一份你遵循的指令列表——它是一个驱动流程并持有状态的程序，而你的部分是点击、粘贴和按回车。

## 何时使用

你可以输入 `/wizard`，agent 也可以自行触发它。当它碰到一个必须由你采取的步骤——一个它无法生成的密钥、一个它无法点击的仪表盘——它给你构建一个向导，而不是把指令写进聊天里、让它们滚走。

当你面前的下一个阻碍是一次仪表盘之旅时，就取用它：

| 情况 | 向导做什么 |
| --- | --- |
| 一个新开发者需要在应用启动前配置六个服务 | 按顺序打开每个仪表盘，捕获密钥，把它们写入 `.env` 和 CI |
| 一次一次性迁移需要以特定顺序翻转开关 | 把不可逆步骤排到确认闸门后面 |
| 一个项目必须一次性从状态 A 移到状态 B | 走完这个转换并报告它做不到的事 |
| 你正要那些步骤写进 README | 改为写一个可执行的版本，它不会那么安静地腐烂 |

不要用它来*决定*要构建什么；那是 [grill-with-docs](https://aihero.dev/skills-grill-with-docs) 和 [to-spec](https://aihero.dev/skills-to-spec) 的工具。

## 前提条件

生成一个不需要任何前提。它写的向导在 bash 上运行，并在阶段设置 GitHub 机密或变量时使用 `gh`。如果 `gh` 缺失或未认证，那个阶段变成一个警告，结束汇总告诉你手动设置什么，而不是让运行失败。

## 阶段

一个**阶段**是单个屏幕上的一个聚焦任务。脚本在阶段之间清屏，所以一个溢出屏幕的阶段会丢掉滚走的部分。你按依赖顺序编排阶段并设置 `TOTAL_STAGES`，它驱动进度显示。

界定范围发生在写一行之前。[技能](https://www.aihero.dev/ai-coding-dictionary/skill)读取仓库而不是冷问：`.env*`、`docker-compose*`、框架配置，以及 `.github/workflows/` 中每一个 `secrets.*` / `vars.*` 引用——每一个都是向导必须产出的值。然后它向你展示有序的阶段列表供确认，只有在那之后才把每个阶段映射到人类遵循的精确路径（"仪表盘 → 开发者 → API 密钥 → 显示测试密钥 → 复制"）。在它不知道当前 UI 的地方，它问你或查文档，而不是编造点击。

对每个捕获的值，界定范围确定它落在哪里：

| 目的地 | 何时 |
| --- | --- |
| 仅 `.env` | 本地开发需要，CI 不需要 |
| GitHub 机密 | CI 读取它，而且是敏感的 |
| GitHub 变量 | CI 读取它，而且是公开的 |
| `.env` 和机密两者 | 本地开发和 CI 都需要 |
| 无处 | 阶段是一个纯粹的动作——翻转一个开关、升级一个计划 |

## 模板已经解决了 UX

[模板](https://github.com/mattpocock/skills/blob/main/skills/engineering/wizard/template.sh) 携带了整个体验：带剩余时间的进度、确认闸门、跨平台 URL 打开（包括 WSL）、机密的隐藏输入、幂等的 `.env` 增补、`gh secret` / `gh variable` 写入，以及一个结束汇总，列出它不得不跳过的一切。`STAGES` 标记上方的一切都是一个固定的库，在每一个向导中都相同，从不用手编辑。一致性就是关键。你的工作只是界定流程范围并编排它的阶段。

写向导的 agent 从不端到端运行它，因为它打开浏览器并等待人类输入。它改为静态验证：`bash -n`、可用时的 `shellcheck`，以及一个追踪，确认每个值都落在界定范围所说的位置，每个 `set_secret` 名称都匹配 CI 中真实的 `secrets.*` 引用。相应地设定你的预期——第一次运行是你的，而那次运行就是测试。

| 你拥有什么 | 怎么处理脚本 |

## 常见问题

**我的 API 密钥最终会进入模型的上下文吗？**

不会。agent 写一个脚本；它不运行它。你自己运行脚本，它用隐藏的终端输入捕获密钥，并直接把它写到 `.env` 或 `gh secret`。向导是一个 CLI，模型与它没有连接。一个注意事项：这适用于向导在运行时捕获的值。如果你在界定范围时把密钥粘贴进聊天，它就在[上下文](https://www.aihero.dev/ai-coding-dictionary/context)里，就像任何其他粘贴的文本一样。

**我能回去修正一个打错的值吗？**

运行中不行。没有后退按钮——阶段向前运行，阶段 3 的错误答案意味着 Ctrl-C 并重新运行。重新运行按设计是便宜的：任何已经写入 `.env` 的值都会被作为默认值提供回来，所以你按回车穿过你做对的阶段，只重新输入错的那个。这出现在发布周，此后一直未关闭："太棒了！不过有一点——有没有办法回去修正你输入的内容？"

有一个相关的开放 bug。`ask` 提示中的方向键插入 `^[[D` / `^[[C` 而不是移动光标，因为提示使用 `read -r` 而不是 Readline（[issue #741](https://github.com/mattpocock/skills/issues/741)）。退格键有效；方向键无效。删回到错误处，而不是把光标移进它。

**它知道我设置过什么吗？**

部分知道，而且比发布反应所假设的少。它在问之前读取仓库——你的 `.env` 文件、`docker-compose`、框架配置、CI 中的 `secrets.*` 引用——所以它把范围界定在真正缺失的值，而不是像 README 那样从零开始。它不做的是检查第三方服务。如果密钥存在于你的 `.env` 中，向导会把它提供回来，回车就保留它；如果你已经创建了 Stripe 账户但从未保存密钥，向导仍然会把你送到仪表盘去拿。

**它在工作流中处于什么位置——在访谈和规格之后？**

没有什么特别的位置。它是独立项，不是链中的步骤。常见的猜测是 `/grill-with-docs → /to-spec → /wizard`，那个序列没问题，但触发是一个手动流程的出现，它可以发生在任何时刻：开始之前、构建中途、或发布很久之后。它也可以作为发现工具——界定范围浮现一个任务的隐藏前提，比如你没想到的三个 API 密钥，在你承诺工作之前。

**它在 Claude Code 之外能用吗？**

产物本身，无条件能用：它只是一个纯 bash 脚本，不关心什么[harness](https://www.aihero.dev/ai-coding-dictionary/harness)生成了它。技能本身是模型调用的，所以它被列在所有地方——在 Claude Code 里输入 `/wizard`，或在 Codex 里输入 `$wizard`，或者只是描述你卡住的设置。模型调用也让它避开了 [#693](https://github.com/mattpocock/skills/issues/693)，Claude 的桌面和网页表面在那里把*用户调用*的技能从[模型](https://www.aihero.dev/ai-coding-dictionary/model)的列表中移除并报告为未安装。

**这不是以前用户调用的吗？**

是的。它现在是模型调用的，所以 agent 在碰到必须由你采取的步骤时会主动触发它。你以前能做的一切仍然有效——模型调用*增加* agent 的触达，从不移除你的，所以 `/wizard` 的行为和以前完全一样。改变的是它退休的失败模式：agent 在构建中途碰到凭据墙，把六个编号步骤倒进聊天让你手动跟随。

**它以前在 `in-progress/` 里——现在在哪？**

`engineering/`，从 v1.2 开始。它从 beta 桶毕业，现在随插件发布，所以它和其余被推广的集合一起到达，而不是需要一个单独的安装。它的行为在毕业时没有改变。

## 正常工作的标志

- 你会看到有序的阶段列表、每个阶段产出的值，并被要求确认——在存在任何脚本之前。
- 每个 URL 都在要求该页的值之前被打开。你从不会被要求粘贴你没有被送去获取的东西。
- 机密盲输。没有敏感的东西回显到你的滚动历史。
- 每个阶段都适合一个屏幕。你仍然需要的任何东西都没有滚走。
- Ctrl-C 和重新运行会从你离开的地方继续，把已经保存的值作为默认值提供。
- 最后一个屏幕列出它写了什么，并分别列出它做不到、必须由你手动完成的东西。

## 在流程中的位置

`wizard` 是一个随时可取的独立项，站在自动化停止、人类必须点击的那条线上。它最近的邻居是 [setup-matt-pocock-skills](https://aihero.dev/skills-setup-matt-pocock-skills)，因为两者都存在是为了让仓库进入工作状态——那个配置这套技能，而 `wizard` 为其他一切生成设置路径。它也与 [implement](https://aihero.dev/skills-implement) 配对：当一个构建落地一个需要凭据或手动切换的功能时，向导就是人类那一半的完成方式。当你不确定哪个技能适合此刻时，[ask-matt](https://aihero.dev/skills-ask-matt) 为你路由。
