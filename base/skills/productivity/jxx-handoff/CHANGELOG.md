# Changelog

## 1.2.0 — 2026-10-27

**交接文档的读者是 agent，补歧义约束**：正文新增一段——写前把「谁接手 / 接着做什么 / 从哪一步起 / 什么算做完」四项写成结论，缺项写「待确认：<缺什么>」；指代写全、路径写绝对；未决事项写状态与下一步，不留「酌情处理」。起因：接续 agent 没有上一轮的对话记忆，指代与含糊默认是接续跑偏的主因；判据同源 `jxx-writing-for-agents` 的「歧义」节。
