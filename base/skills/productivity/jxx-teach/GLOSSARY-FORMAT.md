# GLOSSARY.md 格式

`GLOSSARY.md` 是此教学工作区的规范语言。所有解释、练习和学习记录都应遵循其术语。构建它本身就是学习的一部分：将概念压缩为紧凑定义是用户理解它的证据。

## 结构

```md
# {主题} 术语表

{一到两句话描述此术语表涵盖的主题。}

## 术语

**肌肥大（Hypertrophy）**:
由机械张力和代谢压力在反复训练中驱动的肌肉增长。
_避免_：增肌、变壮

**渐进超负荷（Progressive overload）**:
随时间系统性地增加对肌肉的需求——通过负荷、训练量或强度。
_避免_：加把劲、升级

**RPE（感知用力等级）**:
1-10 的自评一组训练有多吃力，10 是力竭，8 表示还能做两个。
_避免_：费力评分、强度评级
```

## 规则

- **仅当用户理解时才添加术语。** 术语表是压缩知识的记录，不是用户阅读学习的字典。如果用户刚接触一个概念，等到他们能正确使用后再提升到此处。
- **要有主见。** 当同一概念有多个词汇时，选最好的，其余列为应避免的别名。这是语言压缩的方式。
- **保持定义紧凑。** 一到两句话。定义术语*是什么*，而非它做什么或如何做。
- **在定义中使用术语表自身的术语。** 一旦术语进入术语表，到处优先使用它——包括在其他定义内部。这是让复杂术语日后更容易理解的方式。
- **在自然集群出现时使用子标题分组**（例如 `## 解剖学`、`## 编程`）。术语连贯时平铺列表也可以。
- **明确标记歧义。** 如果术语在更广泛的领域中被宽泛使用，注明解决方案："在此工作区中，'组'始终指正式组——热身组单独追踪。"
- **随着理解深化而修订。** 用户第一周写的定义到第六周可能是错的。原地更新；不要留下过时条目。
