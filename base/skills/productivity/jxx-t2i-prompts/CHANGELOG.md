# Changelog

## 1.2.0 — 2026-10-21

内置模板 7 → 27 条，覆盖美女/女性人像全谱系：新增国风 4（唐、宋、旗袍、仙侠）、写实写真 10（现代去网红脸、街拍、日系胶片、韩系 Y2K、婚纱、3D 瓷感人偶、时尚大片、美妆特写、商业头像、赛博霓虹、复古胶片）、角色 2（写实三视图、赛博潮玩 IP）、插画 2（头像、治愈系、niji）。

- 模板统一加 `## 英文版示例` 小节：中文投即梦/万相/可灵，英文投 MJ/SDXL/Flux，不再中英混排。
- 新增 `references/templates/index.md` 目录（按题材分组 + 来源可信度分层）。
- 来源分层：15 条有原文可对照（即梦模板广场 / PromptHub / 优设 / 教程站），其余为社区通行写法归纳（附官方语法口径链接），使用前需自验。

## 1.1.0 — 2026-10-21

全局库写完后自动在项目留一份副本：新增 `.scratch/t2i-prompts/` 项目镜像（`add` / `copy` 自动同步、`mirror` 子命令手动补、`check` 报两边漂移），支持 `--project-home` / `--no-mirror` 与 `T2I_PROJECT_HOME`。

## 1.0.0 — 2026-10-21

初始版本：平台语法对照、八模块骨架、7 个内置模板、无模板时的检索配方、模板沉淀协议，以及零依赖库管理脚本 `prompt-lib.mjs`（list / search / show / new / copy / add / check / init）。

平台口径与检索渠道经一轮一手调研（2026-10-21，来源含 BFL / OpenAI / Google / 阿里云 / 可灵官方文档与社区榜单），已覆盖：无负面词的平台怎么改写、权重语法跨平台不通用、质量词堆砌已过时、模型版本是复现前提。
