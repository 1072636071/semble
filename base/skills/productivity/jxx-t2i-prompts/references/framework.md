# 骨架与词库

模板只是骨架 + 词库的特定组合。看懂每种骨架在解决什么问题，你才能在没有模板时现场拼一个。

## 通用八模块（人像/角色最稳）

[主体描述], [面部特征], [发型与发饰], [服装与配饰], [动作与神态], [场景与背景], [光影与画质], [风格与渲染]

为什么是这八格：前四格定「是谁」，第五格定「在干嘛」（决定姿态自然度），后三格定「看起来像什么」。姿态单独成格，是因为模型把姿势与风格混一起时最容易崩。

## 各家官方/流行的公式（可单独用）

| 公式 | 结构 | 出处 |
| --- | --- | --- |
| 通用七段 | 主体 + 风格 + 场景 + 构图 + 光线 + 质感 + 限制项 | 社区通行 |
| Midjourney 词序 | Subject → Style → Setting → Lighting → Camera → Parameters（靠前权重高） | [v7 指南](https://promptolis.com/blog/midjourney-v7-prompt-guide-2026) |
| Flux 官方 | Subject + Action + Style + Context（10–30 / 30–80 / 80+ 词三档） | [FLUX.2](https://docs.bfl.ml/guides/prompting_guide_flux2) |
| 通义万相官方式 | 基础：主体 + 场景 + 风格；进阶：主体 + 场景 + 风格 + 镜头语言 + 氛围 + 细节 | [官方](https://help.aliyun.com/zh/model-studio/text-to-image-prompt) |
| 可灵五段 | 景别运镜 + 主体 + 具体动作 + 场景光线 + 情绪风格 | [官方](https://klingai.com/quickstart/ai-image-prompt-formula) |
| 导演 brief | 说清要什么 / 什么固定 / 什么可变（自然语言模型适用） | [OpenAI](https://developers.openai.com/api/docs/guides/image-prompting) |

共性：**前半段权重更高**。把不可妥协的（主体、姿态、风格）往前放，可变的（环境细节）往后放。

## 场景 / 产品 / 海报的三套变体

| 类别 | 骨架 |
| --- | --- |
| 人像摄影 | 对象 + 面部细节 + 妆造服 = 人；镜头参数 + 光位 + 后期 是主要抓手 |
| 场景氛围 | 时空天气 → 视觉锚点 → 层次（前中远）→ 镜头视角 → 光线大气 → 色调 → 画幅 |
| 产品广告 | 产品 → 材质工艺 → 卖点可视化 → 构图台面 → 光位 → 背景 → 后期 |
| 海报主视觉 | 主题情绪 → 主视觉图形 → 构图与字位留白 → 色彩体系 → 质感工艺 → 风格流派 → 画幅 |
| 二次元插画 | 角色属性 → 表情动作 → 服装 → 构图镜头 → 背景 → 画法质感 → 色指定 |

## 组装规则

1. **一格一句，逗号分隔，不写完整句子**（自然语言模型如 GPT-image、即梦、Nano Banana 例外，见 platforms.md）。
2. **具体压过形容词**：「磨砂玻璃，水珠凝结」优于「质感很好」。
3. **一格里最多一个空词**：美貌、高级、极致这类词不产生像素差异，超过一个就在挤占真信息。
4. **权重只用在会漂的格**：风格格、画法格。SD 的 `(x:1.3)` 与 Midjourney 的 `x::1.3` 不通用。
5. **负面词按平台取舍**：多数 2026 模型已不靠 `masterpiece, 8k` 提质量，仍吃负面词的才写负面小节。
6. **示例必须能整段复制投喂**，不留占位符。

## 高频失效模式

| 现象 | 原因 | 改法 |
| --- | --- | --- |
| 出 3D / 出插画，不是照片 | 风格格被视觉化 | 前置 `raw photo, photograph`，负面加 `3d, illustration, render` |
| 脸糊 / 五官漂 | 前四格信息冲突 | 删掉形容气质的抽象词，只留可画的结构（脸型、眼型、发式） |
| 手崩 | 姿势格模糊 | 明确手位置，或让手出画 |
| 背景抢戏 | 场景格过长 | 场景压到一句，主体权重抬高 |
| 文字乱码 | 多数模型排不好字 | 只说留白，文字后期 |
| 十张十个样 | 模板槽位填得太自由 | 固定场景格与风格格，只换姿态格做变体 |

## 词库使用法

references/templates/ 下每个模板自带该主题的词库表。要跨主题借词，只借**结构词**（构图、光位、镜头、材质），不借具体对象词——借错对象词是「像但不对」的主因。
