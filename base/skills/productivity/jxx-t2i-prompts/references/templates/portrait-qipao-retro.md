# 旗袍复古民国

结构固定为「主体描述 + 场景细节 + 风格氛围 + 质量要求」，两个经典场景：江南雨巷、复古洋楼。

细雨朦胧的江南青石板巷，一位身着靛蓝色真丝旗袍的女子，28 岁，旗袍绣精致白玉兰花纹，发髻轻挽配翡翠耳坠，手执油纸伞缓缓前行，背景白墙黛瓦间点缀红色灯笼，水面倒映柔和光影，古典水墨淡彩风格，细腻质感与氛围渲染，复古色调，8K。

## 调参备注

- 两个场景（雨巷 / 洋楼）只换「场景细节 + 光线」两格，其余不动就是同系列。
- 丝绒质感要写「丝绒 + 光泽方向」；写「天鹅绒」常被打回塑料。
- 民国洋楼版把光线换成「暖黄灯光 + 光影对比」，胶片刻画质感保留。
