# 治愈系动漫小女孩

白背景 + 大眼睛 + 单一记忆道具。结构极简，批量换装换道具即得系列。

## 骨架

[年龄感 + 角色], [眼睛与五官], [特征道具], [服装], [背景], [光线], [画质]

## 模块词库

| 模块 | 关键词示例 |
| --- | --- |
| 角色 | 一个可爱的动漫小女孩 |
| 五官 | 黑色大眼睛，圆框眼镜，脸部微胖 |
| 特征道具 | 黄色圆片耳环，发夹上一朵玫瑰花，手捧热饮 |
| 服装 | 蓝衣 / 黄色连衣裙，白色领口 |
| 背景 | 白色背景（纯色，无环境） |
| 光线 | 光线很美，柔和均匀 |
| 画质 | 细节丰富，分辨率高，清新 |

## 完整示例

一个可爱的动漫小女孩，黑色大眼睛，戴圆框眼镜，耳朵上挂着黄色圆片耳环，手放在脸上，身穿蓝衣，白色背景，光线很美，画面风格清新，细节丰富，分辨率高。

## 负面提示词

写实皮肤, 复杂背景, 多余人物, 畸形手指, 文字, 水印

## 调参备注

- 白背景是核心：加任何环境就失去「头像贴纸」感。
- 记忆道具（眼镜/耳环/发夹）只给一个主件，多了画面散。
- 换道具 + 换衣色 = 一套角色头像；文案后期配。
