# Changelog

## 1.1.0 — 2026-08-21

修复调查委派环节经常遗忘回写工单与调查结果的问题：
- 调查委派改为闭环式：委派提示词必须显式给出工单绝对路径，并硬性要求 subagent 将「结论+来源+完成时间」写回同一工单、状态改为「已完成」，禁止输出到 docs/report/
- 主 agent 在 subagent 返回后必须亲自回读工单做三验（状态/结论来源/非空），任一不满足判定「调查未闭环」禁止继续 grill
- 三验通过后强制将调查结果即时追加到 context.md「追问记录」
- 强化收尾 C4：工单需含结论与来源且 context.md 已记录调查结果
- 调研Agent-姜小研 与 memorial 集成升级为强制模式，优先级高于自由/严格模式

## 1.0.0 — 2026-07-30

初始版本：

- memorial 目录持久化：context.md 记录诉求、追问、决策、待澄清
- 三阶段工作流：初始化 → Grill 循环 → 收尾（C1-C5 checklist）
- 方案对比提问范式：2-4 方案，各附优点/缺点/推荐
- 续接重验机制：会话中断后旧决策需重新确认
- ADR 门控：三条件判定是否创建 ADR
- 调查委派：sub-task 工单 + subagent 调研闭环
- 回写全局文档：CONTEXT.md / ADR 同步询问
- 补充 README.md / CHANGELOG.md / LICENSE.txt (MIT)
- 修复描述中中文引号，压缩反模式冗余
