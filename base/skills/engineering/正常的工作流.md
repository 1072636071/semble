> **memorial 模式**：需要持久化、可能跨会话的复杂方案，可将各场景中的 `jxx-grill-with-docs` 替换为 `jxx-grill-with-memorial`（支持中断续接、调查委派、收尾审核）。

场景1：新项目初始化
jxx-setup-matt-pocock-skills - 完成初始化

场景2：需求变动
jxx-grill-with-docs 询问需求
jxx-to-spec 创建/修改规格文档
jxx-to-tickets 创建工单
jxx-implement 执行工单
jxx-code-review 代码检视，并提交代码

场景3：疑难 bug 或性能 regression
jxx-grill-with-docs 询问问题现象与上下文
jxx-diagnosing-bugs 复现→最小化→假设→埋点→修复→regression 测试

场景4：测试驱动开发
jxx-grill-with-docs 询问功能范围与验收标准
jxx-tdd 红-绿-重构循环，逐个纵向切片构建功能或修复 bug

场景5：大型模糊目标
jxx-grill-with-docs 询问目标与验收标准

场景6：超大型工作（跨多个 agent 会话）
jxx-grill-with-docs 询问工作范围与边界
jxx-wayfinder 创建共享调查地图，逐个解决直到路径清晰

场景7：代码库架构改善
jxx-grill-with-docs 询问痛点与改善方向
jxx-improve-codebase-architecture 扫描深化机会，可视化报告，grill 选中项

场景8：领域建模与术语统一
jxx-grill-with-docs 询问领域概念与术语歧义
jxx-domain-modeling 构建/锐化领域模型，更新 CONTEXT.md 和 ADR

场景9：模块接口设计
jxx-grill-with-docs 询问模块边界与接缝（seam）位置
jxx-codebase-design 设计深层模块的共享规范与词汇

场景11：设计验证 / 原型探索
jxx-grill-with-docs 询问要验证的设计问题
jxx-prototype 构建一次性原型回答设计问题

场景12：调研与资料收集
jxx-grill-with-docs 询问调研目标与关键问题
jxx-research 基于高可信度一手资料调查问题，保存为 Markdown

场景13：issue triage
jxx-triage 将 issue 推过 triage 状态机

场景14：合并冲突
jxx-resolving-merge-conflicts 解决 git merge/rebase 冲突

场景15：不确定用哪个技能
jxx-ask-matt 路由器，推荐合适的技能或流程
