﻿# jxx-code-review

沿多个轴 review 自固定点以来的变更 — 标准（代码是否遵循仓库的编码标准？）、spec（代码是否匹配原始 issue/PRD 的要求？），委托模式下再加**规则**（是否违反 OCR 解析出的文件级规则组）。各轴作为并行子 agent 运行并并排报告。

维度数由执行模式决定：检测到 `ocr` CLI → 委托模式 **3 维度**；未检测到 → 降级为内置 **2 维度**（标准 + spec）。

## 何时使用

当用户想 review 分支、PR、进行中的变更，或要求"review 自 X 以来"时使用。

## 执行模式

按环境是否安装 `ocr` CLI 自动选择：

| 模式 | 触发条件 | 审查维度 | 说明 |
| --- | --- | --- | --- |
| 委托模式 | 检测到 `ocr` | **3 维度**：标准 + spec + 规则 | OCR 负责文件筛选 / 规则解析 / 范围判定；宿主 Agent 用自身 LLM 执行实际审查。OCR 端无需配置 LLM。 |
| 内置模式（降级） | 未检测到 `ocr` | **2 维度**：标准 + spec | 沿用双轴并行子 agent 流程，无「规则」维度。 |

可用 `--mode delegate` / `--mode builtin` 显式覆盖自动选择。
