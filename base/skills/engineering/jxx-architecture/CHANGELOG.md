# Changelog

## 1.3.0 — 2026-07-06

准则 5 新增「脚本语言约束」：项目脚本优先 TypeScript；审查时检查约束是否存在，缺失则询问用户是否加上。

## 1.2.0 — 2026-07-06

确立基石定位：开篇声明对项目（可索引 / 规则文件 / 一键运行）与 agent（索引优先、子代理并行审查）的双向基线约定。审查模式改为索引优先流程（codebase-memory MCP：search_graph / trace_path / get_architecture），准则 5 新增「代码索引」条目。

## 1.1.0 — 2026-07-06

合并 2025-2026 前沿实践：新增准则 7「文档即操作系统（DDAD）」（规则文件、Spec-First、ADR）；准则 4 增加符号友好；准则 5 增加一键可运行、TDD 纠错器、子代理并行边界；反模式表新增 Vibe Coding；设计自检 +2 项。

## 1.0.0 — 2026-07-06

初始版本。六条 AI 友好架构准则（文件粒度、函数设计、命名注释、架构模式、工程护栏、反模式），支持设计与审查两种模式。
