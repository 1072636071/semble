# jxx-architecture

AI 友好架构（AI-friendly architecture）的设计与审查 — 以 AI agent 为第一读者的代码结构准则。覆盖两种模式：**架构设计**（模块拆分、目录结构、接口与 Schema 设计）和**架构审查**（按准则逐条核对现有结构，输出分级报告）。

## 何时使用

当用户想做架构设计（新系统、模块拆分、目录结构、技术选型）、架构审查（评估现有结构是否利于 AI 协作），或提到上帝文件、深层嵌套、全局状态、AI 可读性时使用。触发词：架构设计、架构审查、AI 友好。

## 相关技能

- `/jxx-codebase-design` — 深模块词汇与接缝设计
- `/jxx-code-review` — 变更级代码审查（标准轴 + spec 轴）
- `/jxx-improve-codebase-architecture` — 扫描代码库寻找深化机会
