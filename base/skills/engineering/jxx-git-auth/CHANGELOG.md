# Changelog

## 1.0.0 — 2026-09-06

初始版本。四项决策来源：memorial `docs/memorial/003-git-auth/`。

- **令牌源外置** — 技能内只记录仓库外机密文件路径，运行时读取；令牌值永不入库、不随 ship 分发
- **模型可自动调用** — 触发词覆盖认证失败、私有仓库、需要 token 等场景
- **仅凭据加载** — 不含 git 操作教学、SSH key、OAuth 流程
- **三平台映射** — cnb（用户名固定 `cnb`）/ GitHub（令牌即身份）/ Gitee（令牌即身份）
- **三条泄漏禁令** — 不落仓库文件与日志、不回显明文、错误输出先脱敏
