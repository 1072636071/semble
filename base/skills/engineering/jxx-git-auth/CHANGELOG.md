- 硬约束改为直陈句式（安全内容不压缩成碎片）

## 1.1.2 — 2026-09-06

令牌源路径改为用户名无关：

- 以 `%USERPROFILE%`（POSIX `~`）表达路径，并给出解析顺序（环境变量 → 运行时 API → 按当前用户名拼 `C:\Users\<用户名>`）
- 明确禁止把具体用户名写进任何技能文件——技能分发到多台机器，写死即失效
- 平台判定同步改为按源文件的 `host` 字段匹配，不再在技能正文写死平台清单

## 1.1.1 — 2026-09-06

声明为默认安装技能：

- frontmatter 显式 `x-install: true`（等价于缺省，但意图自证），随 `ship install` 分发到全部平台用户级目录
- 登记进技能总目录 README 的模型调用段（此前只登记在 engineering 桶 README 与 ask-matt 路由）

## 1.1.0 — 2026-09-06

令牌源文件改造为结构化凭据清单（YAML 块），读取方式改为按字段取用：

- 源文件每条含 `name` / `host` / `api_base` / `remote_user` / `token` / `auth`，可选 `cli_env` 与 `query_param`
- 平台判定直接读 `host`，不再依赖行标签文本匹配
- `remote_user` 用 `@token` 显式表达"令牌即身份"，消除"用户名位填什么"的歧义
- 新增平台只需在源文件追加一条，技能无需改动
- evals 增加一条：源新增平台后按 host 命中

## 1.0.0 — 2026-09-06

初始版本。四项决策来源：memorial `docs/memorial/003-git-auth/`。

- **令牌源外置** — 技能内只记录仓库外机密文件路径，运行时读取；令牌值永不入库、不随 ship 分发
- **模型可自动调用** — 触发词覆盖认证失败、私有仓库、需要 token 等场景
- **仅凭据加载** — 不含 git 操作教学、SSH key、OAuth 流程
- **三平台映射** — cnb（用户名固定 `cnb`）/ GitHub（令牌即身份）/ Gitee（令牌即身份）
- **三条泄漏禁令** — 不落仓库文件与日志、不回显明文、错误输出先脱敏
