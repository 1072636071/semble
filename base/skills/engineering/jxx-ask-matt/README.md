﻿# jxx-ask-matt

本仓库技能的路由器，映射所有用户可触达的技能及其关系。当你不确定该用哪个技能时，问 Matt。

## 何时使用

当用户不确定该用哪个技能、想了解技能之间的关系、或提到"问我"/"ask matt"时使用。

## 相关技能

- `/jxx-grill-with-docs` — 有代码库时打磨想法
- `/jxx-grill-me` — 无代码库时打磨想法
- `/jxx-prototype` — 一次性 prototype 验证设计问题
- `/jxx-to-spec` — 将线程转为 spec
- `/jxx-to-tickets` — 将 spec 拆分为 ticket
- `/jxx-implement` — 实现单个 issue
- `/jxx-tdd` — 测试驱动开发
- `/jxx-code-review` — 双轴代码 review
- `/jxx-triage` — triage 堆积的 bug 和请求
- `/jxx-diagnosing-bugs` — 诊断棘手 bug
- `/jxx-improve-codebase-architecture` — 改善代码库架构
- `/jxx-domain-modeling` — 领域建模
- `/jxx-codebase-design` — 深模块（deep module）设计词汇
- `/jxx-handoff` — 跨会话上下文传递
- `/jxx-research` — 后台研究
