# Changelog

## 1.7.0 — 2026-11-07

- 消除 ADR 三条件与可选章节冲突：凡建 ADR 必写真实备选、选择/拒绝理由及取舍与后果；没有真实备选就不建。
- 新增前检索同主题旧 ADR；完全/部分取代均标明范围并双向互链，保留单文件历史，不增加归档或状态副本。
- 明确 accepted 只描述当前实际执行的决策，并同步更新 ADR eval 期望。
- 目标仓已有 ADR 结构契约时以其为准，本模板只补真实备选与取舍内容；修掉示例编号冲突，取代旧 ADR 要求替换状态行而非叠加，部分取代写清仍有效范围。
