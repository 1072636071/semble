# Style Consistency Checklist — 界面风格一致性审查清单（通用模板）

> 适用范围：由 `seo-audit-template` 生成的 `seo-geo-audit` 子技能。
> **与写作模板（`seo-blog-template`）共用同一样式基准**——写审一致，不打架。生成子技能时用项目设计系统参数实例化（设计令牌、prose-body 渲染规则等）。

## 1. 设计令牌一致性

| # | 检查项 | 严重等级 | 说明 |
|---|--------|----------|------|
| D1 | 无硬编码颜色 | High | 内容为 Markdown，不应出现 `<style>` 或内联 `color:#...`；若用自定义组件须引用设计令牌 CSS 变量（如 `var(--brand-*)`） |
| D2 | 不使用非标准色 | Medium | 不得出现项目设计系统外的色值 |
| D3 | 主色节制 | Medium | 主色单屏 ≤2 处强调 |

> 生成子技能时，将项目设计令牌表（`--brand-primary` 等）写入本节作为基准。

## 2. 排版规范

| # | 检查项 | 严重等级 | 说明 |
|---|--------|----------|------|
| T1 | 无外部字体加载 | Medium | 使用系统字体栈或项目声明字体，不引 Google Fonts |
| T2 | 正文最小 15px | High | 移动端不更小 |
| T3 | 行高 1.6/1.8 | Medium | 正文行高舒适 |
| T4 | 标题行高紧凑 | Medium | H2/H3 行高 1.2–1.25 |

## 3. 内容样式（prose-body）

> 生成子技能时，将项目 prose-body 渲染规则表写入本节。审查时确认文章 Markdown 正确使用对应语义元素，且未被破坏。

| 元素 | 审查要点 |
|------|----------|
| H2/H3 | 字号/字重/颜色由 prose-body 接管，不手写 |
| p | 行高/颜色由 prose-body 接管 |
| ul/ol | 列表样式由 prose-body 接管 |
| blockquote | 引用块样式由 prose-body 接管 |
| table | 表格样式由 prose-body 接管 |
| a | 链接颜色/下划线由 prose-body 接管 |
| strong | 强调样式由 prose-body 接管 |
| img | max-width:100%，圆角由 prose-body 接管 |

## 4. Markdown 语义规范

| # | 检查项 | 严重等级 | 说明 |
|---|--------|----------|------|
| A1 | 语义化 Markdown | Critical | 用 `##`/`###`/列表/表格/引用，而非手写 HTML 或破坏结构的 `<div>` |
| A2 | H2 数量 ≥2 | High | 用 `##` 划分，至少 2 个 |
| A3 | 层级连续 | Medium | 不跳过层级（无 `##` 直接 `####`） |
| A4 | 段落间距由 prose-body 接管 | Medium | 不手写 `<br>` 堆叠或内联 margin |
| A5 | 表格语法正确 | Medium | 标准 `| 表头 |` 表格 |
| A6 | 强调文本用 `**` | Medium | 不用手写 `<span style=color>` |
| A7 | 链接用 Markdown | Low | `[锚文本](/path)`，不用裸 `<a>` 或内联样式 |

## 5. 图片规范

| # | 检查项 | 严重等级 | 说明 |
|---|--------|----------|------|
| I1 | 图片放正确目录 | High | 按项目约定（如 `public/images/`） |
| I2 | 现代格式 | Medium | WebP/AVIF 等现代格式 |
| I3 | alt 必填且描述性 | High | 描述性 alt |
| I4 | 路径正确 | High | 引用路径不 404 |
| I5 | 尺寸合理 | Low | 宽度足够避免放大模糊 |

## 6. 响应式设计

| # | 检查项 | 严重等级 | 说明 |
|---|--------|----------|------|
| R1 | 移动端可读 | High | prose-body 含移动端适配 |
| R2 | 图片自适应 | Medium | `max-width:100%`，不溢出容器 |
| R3 | 触摸目标 ≥44px | Medium | 正文链接/按钮满足 |

## 7. 评分标准

| 等级 | 分值 | 说明 |
|------|------|------|
| A（优秀） | 90–100 | 所有 Critical/High 项通过，Medium 项通过率 ≥80% |
| B（良好） | 75–89 | 所有 Critical 项通过，High 项通过率 ≥80% |
| C（合格） | 60–74 | 所有 Critical 项通过，High 项通过率 ≥60% |
| D（不合格） | <60 | 存在 Critical 项未通过 |

### 加权计算

- Critical: ×3
- High: ×2
- Medium: ×1
- Low: ×0.5

总分 = Σ(通过项 × 权重) / Σ(总项 × 权重) × 100
