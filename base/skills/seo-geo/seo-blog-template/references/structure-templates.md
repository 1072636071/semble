# Content Structure Templates

常见 SEO 格式的紧凑蓝图。替换占位符，将主关键词置于 H1 与前 100 词，删除与意图不符的段落。

## Shared Build Rules

| Element | Include |
|---------|---------|
| Opening | 钩子、问题、承诺、尽早出现主关键词 |
| Proof | 数据、示例、引文、第一手经验或来源/日期引用 |
| Structure | 清晰 H2/H3 层级、短段落、仅在决策处用表格 |
| GEO | 40-60 词定义区块、可引用 takeaway、面向 long-tail 检索的 FAQ |
| Links | 3-5 条内链与 2-3 条权威外链，除非格式需要更多 |
| Ending | 回顾、建议与一个下一步或 CTA |

## Blueprint Matrix

| Format | Goal | Required sections |
|--------|------|-------------------|
| Blog post | 信息型排名 | H1、intro、定义、为何重要、主体段落、常见错误、FAQ、结论 |
| Comparison | 帮读者选择 | 快速结论、对比表、选项摘要、分类赢家、定价、最终结论 |
| Listicle | 排名 `best [topic]` | 摘要表、评判标准、重复的 item card、对比、首选 |
| How-to | 教流程 | 工具/时间/技能等级、编号步骤、示例、排障、FAQ |
| Product review | 购买决策 | 测试背景、概览、优缺点、特性、性能、定价、竞品对比、结论 |
| Pillar page | Cluster 枢纽 | TOC、基础、子主题、战术、示例、FAQ、资源 |
| FAQ page | 问题排名与 FAQ rich results | intro、分组问题、直接答案、进阶问题、CTA |

## Copy-Start Matrix

| Format | Minimal starter |
|--------|-----------------|
| Blog post | `# [Keyword]: [Benefit]` -> hook -> `## What Is [Topic]?` -> 40-60 词定义 -> 主体段落 -> 常见错误 -> FAQ -> 结论 |
| Comparison | `# [A] vs [B]` -> 快速答案 -> 特性/定价表 -> 分类赢家 -> 选 A/B 标准 -> 结论 |
| Listicle | `# [Number] Best [Items] for [Audience]` -> 摘要表 -> 标准 -> 重复 item card -> 对比 -> 首选 |
| How-to | `# How to [Goal]` -> 工具/时间/等级 -> 步骤 -> 示例 -> 排障 -> FAQ -> 下一步 |
| Product review | `# [Product] Review` -> 测试背景 -> 性能结果 -> 优缺点 -> 特性 -> 定价/竞品 -> 购买契合度 -> 结论 |
| Pillar page | `# [Topic]: Complete Guide` -> TOC -> 基础 -> 子主题 -> 框架 -> FAQ -> 资源 |
| FAQ page | `# [Topic]: Frequently Asked Questions` -> 分组问题 -> 简洁答案 -> 对比/定价 -> CTA |

## Section Blocks

| Block | Pattern |
|-------|---------|
| Definition | 40-60 词、直接作答、事实性内容加来源/日期 |
| Summary table | 仅保留关键决策字段；避免装饰 |
| Proof callout | `Key insight: [stat/claim + source/date]` |
| FAQ answer | 40-60 词；先答案后细节 |
| CTA | 一个与搜索意图绑定的下一步 |

## Implementation Checklist

- [ ] 替换占位符并删除无关段落。
- [ ] 将主关键词置于 H1 与前 100 词。
- [ ] 在 H2/H3 自然使用次关键词。
- [ ] 加入证据、示例、来源/日期引用或数据。
- [ ] 在利于 GEO 检索时加入 FAQ 与定义区块。
- [ ] 加入内/外链与描述性图片 alt text。
- [ ] 适用时加入联盟披露。
- [ ] 以匹配最终角度的 meta title 与 description 收尾。
