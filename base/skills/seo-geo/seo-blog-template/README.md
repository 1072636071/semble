# seo-blog-template

SEO/GEO 写作模板（skill-as-generator）——追问收集项目内容架构知识，在项目级技能目录生成固定名 `blog-writer` 子技能。

## 用法

- 「生成写作技能」——首次配置：追问项目内容架构 → 生成 `blog-writer` 子技能
- 「升级写作技能」——模板版本更新后：比对版本 → diff 确认 → 覆盖

## 生成物

生成的 `blog-writer` 子技能内置样式模板与写作/自检 checklist，与 `seo-geo-audit`（审查子技能）共用同一样式基准——写审一致。

## 关联

- ADR 0005（仅项目级分发）、ADR 0006（skill-as-generator + 版本戳升级）
- 配套审查模板：`seo-audit-template`
- references 来源：`seo-content-writing`（五件套）
