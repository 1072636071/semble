# Positioning Frameworks

用这些紧凑框架映射竞品定位、寻找 white space，并把差异化转为可防御的话术。

## Positioning Statements

```text
Classic:
For [target audience], [brand] is the [category] that [key benefit] because [proof].

Extended:
For [audience] who [need], [brand] is the [category] that [functional benefit],
unlike [alternative], because [unique capability]. This matters because [outcome].

Before/After/Bridge:
Before: [painful current state]
After: [desired state]
Bridge: [product] makes this possible by [mechanism].

PAS:
Problem: [struggle]
Agitation: [why it matters now]
Solution: [different solution]
```

## Positioning Map

1. 选买家相关且独立的轴。
2. 标出直接竞品、间接替代与当前位置。
3. 找 white space、拥挤簇与轴本身选错之处。
4. 选一个能力对齐、未被充分服务且可防御的位置。

| Axis Pair | X-Axis | Y-Axis |
|-----------|--------|--------|
| Value | 价格低 -> 高 | 能力基础 -> 高级 |
| UX | 复杂 -> 简单 | 有限 -> 强大 |
| Audience | SMB -> enterprise | 单点方案 -> 平台 |
| Innovation | 成熟 -> 新兴 | niche -> 宽泛 |

| Anti-Pattern | Fix |
|--------------|-----|
| 愿景图 | 先标当前位置，再规划目标位置 |
| 虚荣轴 | 用客户语言验证轴 |
| 仅直接竞品 | 纳入间接工具、服务、电子表格与现状 |
| 静态图 | 每季度或竞品重大发布后刷新 |

## Category Strategy

| Strategy | Use When | Messaging Pattern | Main Risk |
|----------|----------|-------------------|-----------|
| 赢现有 category | 产品在已知框架内明显更优 | `The best [category] for [audience]` | 昂贵的正面交锋 |
| 创 sub-category | 差异化值得独立标签 | `The first [new sub-category]` | 市场未必搜索此词 |
| 创新 category | 现有 category 误导买家 | `Introducing [new category]` | 教育成本高 |
| 重构 category | 现有框架偏袒在位者 | `Stop thinking [old]. Start thinking [new].` | 证据弱时引混乱 |

决策规则：若 SEO 需求与买家语言已存在，优先现有 category 或 sub-category。仅当产品现实无法塞入旧框架时才用新 category 走法。

## Differentiation Audit

| Dimension | Your Approach | Competitor Approach | Strength | Defensibility |
|-----------|---------------|---------------------|----------|---------------|
| Core technology | [tech] | [their tech] | Weak/Med/Strong | Easy/Hard |
| Target audience | [audience] | [audience] | Weak/Med/Strong | Easy/Hard |
| Pricing model | [model] | [model] | Weak/Med/Strong | Easy/Hard |
| Data/network | [advantage] | [advantage] | Weak/Med/Strong | Easy/Hard |
| Methodology | [framework] | [framework] | Weak/Med/Strong | Easy/Hard |

**Only-we test**："Only [company] [does X] because [unique reason]。"若竞品能可信地说出同样的话，则非持久差异化。

```text
Differentiation message:
We're the only [category] that [unique capability],
which means [customer benefit],
so you can [desired outcome].
```

## Messaging Vulnerability Scan

| Vulnerability | Evidence | Counter |
|---------------|----------|---------|
| 承诺-现实落差 | review、支持投诉、流失评论 | 交付证明、客户证据 |
| 具体性缺口 | 模糊宣称、无指标 | 针对特定受众的特定指标 |
| 受众错配 | enterprise 文案打 SMB 痛点，或反之 | 对被忽视的细分说话 |
| 遗留定位 | 旧 category 故事不再成立 | 针对其过时框架定位 |
| 功能堆砌 | 功能清单无结果 | 以业务结果领头 |
| 价格不透明 | 隐藏费用、TCO 不清 | 透明 pricing 或 TCO 对比 |

## Counter-Positioning Patterns

| Pattern | Use When | Example Shape |
|---------|----------|---------------|
| Contrast | 在位者有明显弱点 | `Unlike [competitor], we [strength].` |
| Flanking | 竞品忽视有价值细分 | `Built specifically for [segment].` |
| Reframing | 其强项带来副作用 | `[Feature] sounds good until [consequence].` |
| Elevation | 功能战拥挤 | `What matters is [higher-level outcome].` |
| Specificity | 竞品模糊 | `[metric] for [audience] in [timeframe].` |

## Combined Workflow

1. 映射 category 与竞品位置。
2. 选 category 策略。
3. 起草 positioning statement。
4. 跑 differentiation audit 与 only-we test。
5. 识别话术漏洞。
6. 将结果转为 battlecard。
7. 每季度复检。
