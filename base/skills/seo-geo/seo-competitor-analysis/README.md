# seo-competitor-analysis

将竞品的关键词、内容、backlink、AI 引用与流量份额基准化为优势、劣势与行动计划。

## 用途

运行 8 步竞品分析：Identify → Gather Data → Keyword Rankings → Content Strategy → Backlink Profile → Technical SEO → GEO/AI Citations → Synthesize。输出对比表、优势/劣势与 Immediate / Short-term / Long-term 行动计划。
