# seo-backlink-analysis

为 off-page SEO 分析外部 referring domain、anchor text 分布、toxic link 与竞品链接缺口。

## 用途

运行 7 步 backlink 分析：Profile Overview → Link Quality → Toxic Links → Competitor Comparison → Link Building Opportunities → Track Changes → Generate Report。输出含 toxic ratio、link-building 动作与竞品位置的 backlink 报告。
