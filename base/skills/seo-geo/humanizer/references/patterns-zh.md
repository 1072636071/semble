# 中文 AI 味模式库

> A 类 = 词面触发，脚本 `scripts/scan_ai_flavor.py` 自动扫描。
> B 类 = 结构/语义触发，只能由你（模型）判断并扣分。
> 严重度 ⭐⭐⭐ = 读者最反感、优先改。

---

## A1 · 开头套话（开头 200 字内 ×1.5 加权）

| 触发 | 度 | 改写方向 |
|---|---|---|
| 在当今社会 / 在当今时代 | ⭐⭐⭐ | 删，或换成具体场景 |
| 随着 XX 的发展 / 近年来 XX 日益 | ⭐⭐⭐ | 用具体时间替代 |
| 众所周知 / 毋庸置疑 / 不可否认 | ⭐⭐⭐ | 删，或"大部分人都……" |
| 伴随着 XX 的快速发展 | ⭐⭐⭐ | "XX 出现后" |
| 在 XX 的背景下 | ⭐⭐ | 改成具体语境 |
| 一直以来，XX 都… | ⭐ | "过去几年" |

> 在当今社会，人工智能技术日益发展，众所周知已经渗透到各行各业。
> → AI 已经渗到各行各业。从客服到代码生成，几乎没有它不碰的角落。

## A2 · 转折/连接词滥用

| 触发 | 度 | 改写方向 |
|---|---|---|
| 此外 / 与此同时 / 不仅如此 | ⭐⭐ | 直接接上，或用句号断开 |
| 然而 / 尽管如此 | ⭐ | 靠上下文连接，多用句号分段 |
| 因此 / 综上所述 / 总而言之 | ⭐⭐ | 删，结论直说 |
| 一方面…另一方面… | ⭐⭐ | 拆成两段 |
| 既…又…还… | ⭐⭐ | 拆成两个动作 |
| 无可厚非 / 瑕不掩瑜 | ⭐⭐⭐ | 删 |

> 这一举措不仅提升了效率，此外还降低了成本。总而言之，效果显著。
> → 效率提上来了，成本也降了不少。

| 深入探讨 / 深入分析 / 深入研究 | ⭐⭐⭐ | "看一下""聊聊" |
| 核心 / 关键 / 精髓 / 要义 | ⭐ | 多数可删 |
| 高效 / 便捷 / 智能化 | ⭐ | 换成具体数字 |
| 高度重视 / 深入推进 / 扎实开展 | ⭐⭐⭐ | "认真做了" |
| 积极探索 / 有效落实 / 持续优化 | ⭐⭐⭐ | 删 |
| 凝聚共识 / 汇聚合力 / 协同推进 | ⭐⭐⭐ | 删 |
| 全方位 / 多角度 / 立体化 / 全链路 | ⭐⭐ | 删或具体化 |

> 我们高度重视用户体验，深入推进产品优化，全方位提升服务质量。

## A4 · 结尾升华（末段 ×2 加权，影响最大）

| 触发 | 度 | 改写方向 |
|---|---|---|
| 让我们共同 / 让我们一起 | ⭐⭐⭐ | 删，或改成具体行动 |
| 未来可期 / 任重道远 | ⭐⭐⭐ | 删 |
| 在 XX 的道路上不断前行 | ⭐⭐⭐ | 删 |
| 为 XX 贡献力量 / 谱写新篇章 | ⭐⭐⭐ | 删 |
| 砥砺前行 / 扬帆远航 | ⭐⭐⭐ | 删 |
| 展望未来，XX 将… | ⭐⭐ | 改成具体计划 |
| 总之 / 希望对你有所帮助 / 欢迎点赞收藏 | ⭐⭐⭐ | 换成真收束，或戛然而止 |

> 让我们共同期待，在数字化转型的道路上不断前行，谱写新篇章。
> → 下个季度重点做两件事：把审批从 1 天压到 2 小时，把月报改成周报。

## A5 · 排比 / 三段式 / 伪对仗

| 触发 | 度 | 改写方向 |
|---|---|---|
| X、X 与 X 三段列举 | ⭐ | 改成两项或四项 |
| 一是…二是…三是… | ⭐⭐ | 改成自然过渡 |
| 既…又…还… | ⭐⭐ | 拆句子 |
| 这不仅…也…更… | ⭐⭐⭐ | 砍掉中间环节 |
| 从 X 到 Y，从 X 到 Y | ⭐⭐ | 删 |
| 首先…其次…最后（全篇僵硬分点） | ⭐⭐ | 能连成一段就连 |

> 这不仅体现了技术创新的力量，也彰显了人文关怀的温度，更展示了企业文化的深厚底蕴。
> → 背后是技术团队和文化团队一起搭的。

| 一站式 / 全链路 / 闭环 | ⭐⭐ | 改成具体描述 |
| 抓手 / 打法 / 颗粒度 | ⭐⭐⭐ | 删 |
| 底层逻辑 / 顶层设计 | ⭐⭐⭐ | 删 |
| 沉淀 / 拉通 / 对齐 | ⭐⭐ | 换成大白话 |

> 我们致力于打造一站式全链路解决方案，赋能业务增长。
> → 我们做了一个工具，把 5 个流程合到一个页面上。

## A7 · 模糊归因 / 假权威

| 触发 | 度 | 改写方向 |
|---|---|---|
| 专家指出 / 业内人士表示 | ⭐⭐⭐ | 给具体名字 + 出处 |
| 据相关研究表明 / 大量数据表明 | ⭐⭐⭐ | 给具体研究/数字 |
| 有学者认为 / 专家普遍认为 | ⭐⭐⭐ | 删或具体化 |
| 众所周知 / 大家普遍认为 | ⭐⭐ | 删 |
| 客观来说 / 从某种角度讲 / 毫无疑问 | ⭐⭐⭐ | 删空壳，用具体事实或真实态度顶上 |

> 专家指出，AI 在医疗领域具有广阔的应用前景。
> → 斯坦福 2024 年的报告显示，AI 辅助诊断在皮肤癌识别上准确率比医生高 5 个百分点。

## B 类 · 结构与语义（脚本扫不到，你来判断）

| 编号 | 问题 | 扣分 | 判定要点 |
|---|---|---|---|
| B1 | 句式单一化 | -10 | 连续 5 段以上句式雷同；每段以"X。"机械收尾；全文都是动宾结构 |
| B1b | 完美主义陷阱 | -5 | 每句都工整对仗、无可挑剔，缺口气缺人味。允许短句糙句 |
| B2 | 段落对称结构 | -8 | 每段都是"观点+例子+总结"总分总模板 |
| B3 | 标题层级滥用 | -3/个 | 一段一标题、四字成语标题、标题带 emoji、标题全粗体加冒号 |
| B4 | 总结段空泛 | -10 | 结尾无具体数字/事实，放之四海而皆准 |
| B5 | 缺乏具体细节 | -15 | 全文无数字、时间、地点、文件名、版本号、人名 |
| B6 | 缺乏个性化声音 | -12 | 无"我/我们"视角、无不确定性表达、无吐槽自嘲、像维基百科 |
| B6b | 情感缺失 | -8 | 像说明书，没有立场好恶，感觉不到"谁在说话" |
| B7 | 标点滥用 | -5 / -3 | 每 500 字 ≥3 个破折号「——」；全文 ≥3 处连续感叹号 |

**C 类 · 中英夹杂**：关键术语不给中文解释、一会儿"用户"一会儿"User"、中文为主却夹大段英文（典型 GPT 直出）。-2/处，上限 -10。
