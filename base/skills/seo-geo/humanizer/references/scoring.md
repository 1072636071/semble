# AI 味评分算法

> **单一 0-100 分制。100 = 完全人话，0 = 完全 AI 体。**
> 脚本负责词面 + 可自动化的结构项；模型负责语义/结构项（B 类 / F 类）。两者扣分相加。

```
AI味指数 = max(0, 100 - 词面扣分 - 脚本结构扣分 - 模型结构扣分)
```

---

## 1. 词面扣分（脚本算）

| 类别 | 单次扣分 | 类别上限 |
|---|---|---|
| A1 开头套话 | -8 | -25（开头 200 字内 ×1.5） |
| A2 转折连接词 | -2 | -15 |
| A3 形容词堆砌/官腔 | -4~5 | -25 |
| A4 结尾升华 | -6~8 | -20（末段 ×1.5） |
| A5 排比三段式 | -3~6 | -15 |
| A6 营销体/黑话 | -3~5 | -25 |
| A7 模糊归因 | -3~5 | -20 |
| A8 伪深度 | -4~5 | -15 |
| A9 假大空成语 | -3~4 | -12 |
| A10 模板口水 | -4~7 | -20 |
| C 中英夹杂 | -2 | -10 |
| E1-E21 英文模式 | -2~5 | -20 |

**重复衰减**：同一模式第 N 次出现，扣分 × min(N, 3)。
**类别封顶**：每个类别累计扣分不超过上表上限，防止长文被低质量命中撑爆。

---

## 2. 脚本结构扣分（自动）

| 项 | 扣分 | 判定 |
|---|---|---|
| 破折号过多 | -5 | 每 500 字 ≥ 3 个「——」 |
| 感叹号过多 | -3 | 全文 ≥ 1 处「！！！」或 ≥3 处「!!」 |
| 无具体数字 | -12 | 全文无任何数字 |
| 无第一人称 | -8 | 全文无「我/我们/I/we」 |
| 标题 emoji 滥用 | -3/个（上限 -9） | emoji ≥ 3 个 |

---

## 3. 模型结构扣分（人工/模型判断）

中文见 `patterns-zh.md` B 类，英文见 `patterns-en.md` F 类：

| 项 | 扣分 |
|---|---|
| 缺乏具体细节（无数字/名字/时间/版本号） | -15 |
| 缺乏个性化声音（无我/我们、无不确定性表达） | -12 |
| 句式单一化 / 完美主义陷阱 | -10 ~ -15 |
| 总结段空泛（放之四海而皆准） | -10 |
| 段落对称结构（每段总分总） | -8 |
| 情感缺失（像说明书） | -8 |
| 标题层级滥用 | -3/个 |
| 标点滥用 | -5 |

---

## 4. 等级

| 分值 | 等级 | 动作 |
|---|---|---|
| 85-100 | 🟢 人话 | 直接交付 |
| 70-84 | 🟡 微 AI 味 | 局部优化后交付 |
| 50-69 | 🟠 中度 AI 味 | 大改 1-2 段 |
| 30-49 | 🔴 重度 AI 味 | 重写 |
| 0-29 | ⚫ 完全 AI 体 | 整段重写 |

**交付线：70 分。** 低于 70 回到改写阶段，只攻 Top 3，然后复评。分数必须上涨。

---

## 5. 脚本输出 JSON

```json
{
  "score": 32,
  "level": "重度 AI 味",
  "level_emoji": "🔴",
  "deductions": { "lexical": -45, "structural": -23 },
  "stats": { "total_chars": 1234, "total_lines": 56, "ai_pattern_count": 23 },
  "hits": [
    { "code": "A4", "name": "结尾升华", "pattern": "让我们共同", "text": "让我们共同期待…",
      "line": 42, "column": 3, "severity": "high", "penalty": -9, "raw_penalty": -6 }
  ],
  "suggestions": ["结尾升华 — 删掉'让我们共同'等空话，给具体计划（命中 2 处）"]
}
```

## 6. 调用约定

```bash
python3 scripts/scan_ai_flavor.py article.md          # Markdown 报告
python3 scripts/scan_ai_flavor.py --json article.md   # JSON
python3 scripts/scan_ai_flavor.py article.md -o r.md  # 写文件
cat article.md | python3 scripts/scan_ai_flavor.py -  # 管道
```
