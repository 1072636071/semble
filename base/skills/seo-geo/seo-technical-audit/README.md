# seo-technical-audit

审计 crawlability、indexing、Core Web Vitals、robots.txt、sitemap、canonical、redirect 与 migration 的技术 SEO 健康度。

## 用途

执行 9 步技术 SEO 审计：Crawlability → Indexability → Site Speed & Core Web Vitals → Mobile-Friendliness → Security & HTTPS → URL Structure → Structured Data → International SEO → Summary。产出带评分的诊断与优先修复计划。

## 触发词

- "check technical SEO"、"技术SEO"、"网站速度"、"核心网页指标"、"索引问题"、"Google找不到页面"、"site speed"、"Core Web Vitals"、"crawlability"、"robots.txt"、"site migration"
- 迁移前审计、LLM crawler 处理、bulk URL 审计

## 关联

- `seo-router`：技能路由器，本技能由其分发
- `seo-audit-template`：审查模板，本件与其技术类 references 指针引用而非复制
- `seo-content-writing`：从基础设施问题继续到页面级修复
