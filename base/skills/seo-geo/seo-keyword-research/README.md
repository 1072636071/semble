# seo-keyword-research

为 SEO 与 GEO 规划发现、评分并聚类关键词。

## 用途

运行 8 阶段关键词研究工作流：Scope → Discover → Variations → Classify → Score → GEO-Check → Cluster → Deliver。输出排好序的 keyword brief，含 volume、difficulty、intent、topic cluster 与 Quick Win / Growth / GEO 机会。
