# Topic Cluster Templates

构建 topic cluster 的规划工作表与度量框架，避免产出过多薄 cluster 页。

## Pillar Viability

| Field | Input |
|-------|-------|
| Pillar topic | [broad topic] |
| Pillar keyword | [head keyword] |
| Monthly volume | [volume] |
| Keyword difficulty | [KD] |
| Business relevance | [1-5] |
| Current rank | [position / not ranking] |
| Competitor coverage | [who owns this topic] |
| Estimated cluster size | [subtopics] |
| Existing assets | [URLs/files to repurpose] |

当以下多数成立时推进：

- 存在 8-12 个可行 subtopic。
- 合并 cluster volume 大于 5,000/月，或在战略上即便 volume 较低也重要。
- topic 直接关联产品/服务专长。
- 你能加入原创专长、数据、示例或工具。
- 竞品尚未建成无法击败的 cluster。

## Architecture Patterns

| Pattern | Best For | Shape |
|---------|----------|-------|
| Classic hub-spoke | 教育类 topic | Pillar 链向 definition、benefits、examples、tools、mistakes、checklist |
| Layered cluster | 技术类 topic | Beginner -> intermediate -> advanced 分支 |
| Use-case cluster | 产品/服务类 topic | SMB、enterprise、agency、ecommerce、industry 变体 |
| Process cluster | How-to 类 topic | Research -> plan -> execute -> measure |

## Internal Linking Rules

| Rule | Requirement |
|------|-------------|
| Cluster -> pillar | 每个 cluster 页都链接到 pillar |
| Pillar -> cluster | Pillar 链向每个核心 cluster 页 |
| Cluster -> cluster | 每个 cluster 页链向 2-3 个相关兄弟页 |
| Anchor text | 描述性且具上下文，绝不泛用 `click here` |
| Placement | 优先正文；footer/sidebar 链接为辅 |

| Cluster Size | Min Links/Page | Max Links/Page | Pillar Link Strategy |
|--------------|----------------|----------------|----------------------|
| 5-8 pages | 2-3 | 5-6 | 链向每个 cluster 页 |
| 9-15 pages | 3-4 | 6-8 | 链向每个 cluster 页 |
| 16+ pages | 4-5 | 8-10 | 链向 top 页；其余分组 |

## Build Sequence

| Phase | Publish |
|-------|---------|
| 1 | 先发 pillar 页 |
| 2 | 3-4 个最低 difficulty 的 cluster 页 |
| 3 | 最高 volume 的页 |
| 4 | 其余 niche subtopic |
| 5 | 刷新 pillar 链接并更新过时 cluster |

| Team Size | Typical Cluster Time | Cadence |
|-----------|----------------------|---------|
| Solo | 6-8 周 | 每季度 1 个 |
| Small team | 3-4 周 | 每月 1 个 |
| Medium team | 2-3 周 | 每月 2 个 |
| Large team | 1-2 周 | 每周 1 个 |

## Anti-Patterns

| Anti-Pattern | Fix |
|--------------|-----|
| 仅 footer cluster 链接 | 将链接移入相关正文段落 |
| 孤儿 cluster 页 | 加 pillar 与兄弟链接 |
| 过度链接 | 保持链接相关；通常每页 5-10 个内链 |
| 仅 Pillar 单向链接 | 在上下文支持处加 2-3 个兄弟链接 |
| 薄 subtopic | 并入 pillar 或等证据充足再做 |

## Measurement

| Timeframe | Review | Action If Weak |
|-----------|--------|----------------|
| 2 周 | 索引 | 修 crawl/内链问题 |
| 1 月 | 早期排名与流量 | 改进 title、meta、内链 |
| 3 月 | 排名趋势 | 刷新内容、补缺失 subtopic、建设链接 |
| 6 月 | 全 cluster 表现 | 大改、修剪或转向 |

| Health Dimension | 1 Poor | 3 Average | 5 Excellent |
|------------------|--------|-----------|-------------|
| Traffic growth | 下降 | 持平 | 10%+ MoM |
| Keyword coverage | <20 | 20-50 | 50+ |
| Top 10 rankings | 0 | 1-5 | 5+ |
| Freshness | 12+ 月未更新 | 6 月内更新 | 3 月内更新 |
| Internal linking | 缺失/孤儿 | 基础 | 完整交叉链接 |
| Completeness | <50% | 50-80% | 80-100% |

Health score = 各维度均分。低于 3.0 = 有风险；低于 2.0 = 战略复盘。
