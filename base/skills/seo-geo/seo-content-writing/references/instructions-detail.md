# SEO Content Writer — Detailed Instructions

SEO Content Writer 技能的紧凑工作流、写作前 checklist、问题处理与内容类型快速起步。

## 1. Gather Requirements

```markdown
### Content Requirements

**Primary Keyword**: [main keyword]
**Secondary Keywords**: [2-5 related keywords]
**Target Word Count**: [length]
**Content Type**: [blog/guide/landing page/etc.]
**Target Audience**: [who this is for]
**Search Intent**: [informational/commercial/transactional]
**Tone**: [professional/casual/technical/friendly]
**CTA Goal**: [desired action]
**Competitor URLs**: [top ranking pages to beat]
```

## 2. Load CORE-EEAT Constraints

写作时应用以下 16 项高权重条目：

| ID | Standard | How to Apply |
|----|----------|--------------|
| C01 | Intent Alignment | 标题承诺与交付内容匹配 |
| C02 | Direct Answer | 核心答案出现在前 150 词内 |
| C06 | Audience Targeting | 在 intro 或开篇段落声明内容面向谁 |
| C10 | Semantic Closure | 结论回应开篇问题并给出下一步 |
| O01 | Heading Hierarchy | 清晰的 H1 → H2 → H3 结构 |
| O02 | Summary Box | 顶部附近包含 TL;DR 或 key takeaways 区块 |
| O06 | Section Chunking | 段落保持 3-5 句、每节一个主题 |
| O09 | Information Density | 删除填充内容 |
| R01 | Data Precision | 主题支持时包含至少 5 个带单位的精确数字 |
| R02 | Citation Density | 每 500 词至少 1 处外部引用 |
| R04 | Evidence-Claim Mapping | 每个实质性声明都有证据、示例或引用 |
| R07 | Entity Precision | 人名与组织名使用全称 |
| C03 | Query Coverage | 覆盖至少 3 种查询变体或追问 |
| O08 | Anchor Navigation | 草稿有 3+ 个 H2 时加 TOC |
| O10 | Multimedia Structure | 为媒体加 caption 与有意义说明 |
| E07 | Practical Tools | 相关时提供至少 1 个模板、checklist、计算器或 worksheet |

## 3. Research and Plan

映射：
- SERP 格式与平均深度
- 主、次、相关与问题关键词
- 独特角度或差异化点

## 4. Create Optimized Title

提供 2-3 个标题选项，各自标注长度、关键词位置与奏效原因。

## 5. Write Meta Description

给出一条推荐描述，含关键词、价值主张与 CTA。

## 6. Structure Content and Write

采用：
- H1
- 引言，含钩子、承诺与尽早出现的关键词
- 匹配搜索意图的 H2 段落
- 需要时的 H3 子主题
- 面向 snippet 机会的 FAQ 段落
- 结论，含回顾 + CTA

## 7. Apply On-Page SEO Best Practices

关键检查：
- 主关键词出现在 title、H1、intro、至少一个 H2 与结论
- 3-5 句段落
- 在提升可扫读性处使用项目符号、表格与加粗
- 2-5 条内链与 2-3 条权威外链
- snippet 友好时 FAQ 答案用 40-60 词

## 8. Add Internal and External Links

```markdown
### Link Recommendations

**Internal Links**
1. "[anchor text]" → [/your-page-url] — [reason]

**External Links**
1. "[anchor text]" → [authoritative-source.com] — supports [claim]
```

## 9. Final SEO Review and CORE-EEAT Self-Check

按 10 项 SEO 因素给草稿打分：
- Title
- Meta description
- H1
- Keyword placement
- H2 coverage
- Internal links
- External links
- FAQ
- Readability
- Word-count fit

随后以上述 16 项 CORE-EEAT 条目做 Pass / Warn / Fail 验证。

## Issue Classification

**Auto-correct** 并在 `### Changes Made` 中记录：
- 过长的 title 或 meta description
- 缺失的 alt text
- 重复的 H2
- 过度的关键词重复
- 长页缺失 TOC
- 需要拆分的段落

```markdown
### Changes Made During Self-Check

| Item | Original | Fixed |
|------|----------|-------|
| Meta description | 185 chars | 158 chars — removed extra qualifier |
```

**改动前需询问用户**：
- H1 措辞
- 语气
- 重大长度调整
- 需要弱化的强声明
- 无法核实的外链或统计

## Content Type Templates

- **How-To Guide**: `Write a how-to guide for [task] targeting [keyword]`
- **Comparison Article**: `Write [Option A] vs [Option B] for [keyword]`
- **Listicle**: `Write "X Best [Items] for [Audience]" targeting [keyword]`
- **Ultimate Guide**: `Write an ultimate guide about [topic] targeting [keyword]`

## Tips for Success

匹配意图、前置价值、使用证据、先为人写、定期刷新高价值内容。
