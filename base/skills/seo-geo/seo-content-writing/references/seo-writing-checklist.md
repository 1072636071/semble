# SEO Writing Checklist and Content Template

起草 SEO 内容的紧凑 checklist——内容有用、可扫读、并就绪于 CORE-EEAT 审查。

## On-Page Checklist

| Area | Required checks |
|------|-----------------|
| Keyword placement | 主关键词出现在 title、H1、前 100 词、至少一个 H2、结论与 meta description；次词出现在 H2/H3；相关实体贯穿正文。 |
| Search intent | 内容类型、角度、深度与 CTA 匹配主流 SERP 意图；混合意图页先回答主要意图。 |
| Quality | 覆盖全面、有原创洞察或数据、可执行 takeaway、示例与专家/来源支撑（声明需要证据时）。 |
| Readability | 3-5 句段落、句长多变、密集点用项目符号/表格、仅关键短语加粗、长文加 TOC。 |
| Technical | 2-5 条相关内链、2-3 条权威外链、描述性图片 alt text、简洁的关键词前置 URL slug。 |
| Snippet targeting | 定义型答案 40-60 词、how-to 查询用有序步骤、对比用表格、FAQ 答案简洁。 |

## Copy-Start Template

```markdown
# [H1 with Primary Keyword]

**Meta Description**: [150-160 char value proposition with keyword and CTA]

[Hook] [Problem statement] [Promise: what the reader will learn] [Primary keyword naturally]

## [H2 with Secondary Keyword]
[1-2 sentence setup]
[Useful explanation with evidence, examples, or data]

### [H3 if needed]
- [Actionable point]
- [Actionable point]
- [Actionable point]

## [H2 for next major section]
> **Pro Tip**: [Specific, non-obvious implementation note]

| Comparison point | Option A | Option B |
|------------------|----------|----------|
| [Factor] | [Evidence] | [Evidence] |

## Frequently Asked Questions

### [Question from PAA or common query]?
[Direct 40-60 word answer that can stand alone as a snippet.]

## Conclusion
[Summarize key points, restate the primary keyword naturally, and give one clear CTA.]

**Sources**: [Source name + URL + access date], [Source name + URL + access date]
```

## Snippet Patterns

| Snippet type | Pattern |
|--------------|---------|
| Definition | `[Term] is [clear definition]. It matters because [outcome].` 保持 40-60 词。 |
| List | 在 H2 下引入列表，再用平行措辞的编号或项目符号项。 |
| Table | 用简单表头、每格一个观点；移动端避免过宽表格。 |
| How-to | 每个动作标 `Step 1`、`Step 2`，并在步骤前给出前置条件。 |
| FAQ | 先直接作答，再在下一句补充细节或注意事项。 |

## Example Calibration Card

用此卡替代复制整篇样例文章：

| Field | Example shape |
|-------|---------------|
| User request | `Write an SEO article about [topic] for [audience] targeting [keyword].` |
| H1 | `[Primary keyword]: [benefit/audience hook]` |
| Meta | `[Primary keyword] + concrete benefit + CTA, 150-160 chars.` |
| Intro | 钩子、痛点、承诺，然后 3-5 条说明读者将学到什么。 |
| Evidence | 为统计引用当前来源；绝不交付无日期的陈旧 benchmark 声明。 |
| FAQ answer | 40-60 词，首句直接，需要时加一条注意事项。 |
| CTA | 一个与意图匹配的动作：订阅、下载、预约、对比或购买。 |

## Final Self-Check

- [ ] 草稿在推销之前先回答主流搜索意图。
- [ ] 每个依赖数据的声明都有具名来源与日期。
- [ ] 内链支撑主题路径，而非仅凑链接数。
- [ ] 标题单独读时构成有用大纲。
- [ ] FAQ 答案足够直接以命中 featured snippet。
- [ ] 结论给出一个明确的下一步动作。
