# seo-content-writing

编写 SEO 优化的文章、博客帖子、落地页与产品描述，覆盖关键词、标题层级、snippet 与证据边界。

## 用途

运行 9 步内容写作工作流：Gather Requirements → Load CORE-EEAT → Research & Plan → Create Title → Write Meta → Structure & Write → On-Page Best Practices → Add Links → Final Review。产出可发布的草稿，含 meta description、H1/H2 结构与 FAQ 段落。

## 触发词

- "write SEO content"、"SEO文章写作"、"内容优化"、"帮我写文章"、"create blog post"、"SEO copywriting"
- 编写面向特定关键词的内容
