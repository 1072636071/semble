# seo-router

SEO/GEO 技能族族内路由器——用自然语言路由到审查模板、写作模板、五件套或已生成的子技能；检测套件缺失时引导安装。

## 用法

- 「帮我查关键词」→ `seo-keyword-research`
- 「审查这篇文章」→ `seo-geo-audit`（或 `seo-audit-template` 生成）
- 「写一篇博客」→ `blog-writer`（或 `seo-blog-template` 生成）

## 关联

- ADR 0005（仅项目级分发 + router 兼任安装器）
- 族内 8 个技能 + 2 个生成子技能
- 与工程族 `jxx-ask-matt` 并列，一族一路由
