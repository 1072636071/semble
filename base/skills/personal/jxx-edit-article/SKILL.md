# 编辑文章

## 输入

- 待编辑的文章草稿（可以是文本、文件路径或对话中的段落）。
- 用户可能附加的编辑偏好（如"更简洁""更正式"）。

## 输出

- 编辑后的文章，保留原文结构骨架但改进章节顺序、清晰度与文字精炼度。

## 前置条件

- 已明确待编辑文章的内容与目标读者。
- 无法获取文章时，先向用户请求，不猜测。

## 步骤

1. 首先，根据标题将文章划分为章节。思考每个章节要表达的核心观点。

   信息构成有向无环图，信息片段之间可能存在依赖关系。确保章节及其内容的顺序符合这些依赖关系。

   与用户确认章节划分。

2. 对每个章节：

   2a. 重写该章节以提升清晰度、连贯性和流畅度。每段最多 240 个字符。

   2b. 检查该章节是否与相邻章节存在重复信息；如有重复，合并或删除，保留唯一信息源。

   2c. 精炼文字：删除冗余词、陈词滥调与填充短语；用具体名词和主动语态替换模糊表达。

3. 重组检查：重新审视整体章节顺序，确认符合依赖关系；必要时与用户确认顺序调整。

4. 全文校对：检查格式一致性（标题层级、列表、代码块）与错别字、标点。

## 异常处理

- 用户未提供文章：请求用户提供后中止，不自行编造内容。
- 章节划分与用户意图冲突：回到步骤 1 重新确认。
- 段落超过 240 字符限制：在 2a 中持续重写直到满足。
