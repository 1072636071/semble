# 游戏角色 CG

出「角色设定图」而不是「插画」：加三视图、纯色背景、设定稿语汇。

## 骨架

[角色身份 + 世界观], [体型比例 + 面容], [服装 + 材质 + 装备], [姿势/视图], [背景], [光照], [渲染与画质]

## 模块词库

| 模块 | 可用词 |
| --- | --- |
| 角色身份 | 女剑客，末世雇佣兵，蒸汽朋克机械师，东方仙侠修士 |
| 体型面容 | 八头身，纤细但有力量感，锁骨清晰，眉眼锋利 |
| 服装装备 | 深色皮革束腰，金属护肩，织锦长袍，机械义肢，符文长剑 |
| 姿势视图 | character turnaround sheet，正面/侧面/背面三视图，中性站姿，A-pose |
| 背景 | 纯灰色背景，plain background，无环境干扰 |
| 光照 | 三点布光，柔和顶光，边缘轮廓光 |
| 渲染画质 | 3D CG 渲染，Unreal Engine 5，高精度材质，game-ready model，PBR 材质 |

## 完整示例

女剑客角色设定图，八头身纤细但有力量感，眉眼锋利，深色皮革束腰配金属护肩与织锦长袍，手持符文长剑，正面侧面背面三视图并排，中性站姿 A-pose，纯灰色背景，三点布光加边缘轮廓光，3D CG 渲染，Unreal Engine 5 画质，PBR 材质，高精度角色建模。

## 负面提示词

busy background, scenery, motion blur, inconsistent design between views, extra limbs, low poly, flat shading

## 调参备注

- 三视图经常只出一个人 → `character sheet, multiple views of the same character, front view side view back view`，多数模型仍需 2-3 张挑。
- 材质想区分布料/金属 → 逐件写材质：`brushed steel, worn leather, silk with sheen`。
- 要能进建模管线 → 补 `T-pose, symmetrical, blueprint-style annotations`。
