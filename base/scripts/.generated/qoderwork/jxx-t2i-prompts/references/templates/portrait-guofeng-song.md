# 宋制清雅人像

低饱和、留白、青绿调。与唐风的富丽正相反：越克制越对。

## 骨架

[朝代 + 年龄 + 气韵], [形制与配饰], [道具], [场景], [光线与大气], [色调], [构图留白], [画质]

## 完整示例

超写实国风，24 岁宋制清雅女子，穿宋制褙子配百迭裙，素色缘边，手持团扇，站在竹林中，晨光透过竹叶形成丁达尔光柱，薄雾轻笼，青绿低饱和色调，高光泛白，暗部发灰，留白构图人物偏左，大量负空间，胶片颗粒，8K 超写实。

## 调参备注

- 留白是这套的命门：人物偏一侧，另一侧留 1/3 以上空，标题后期排。
- 太灰就加「一抹暖褐」当视觉锚点（竹叶/衣缘），别整体提饱和。
- 与唐风成对使用：同一人物描述换形制格 → 一套「唐宋双版」国风系列。
