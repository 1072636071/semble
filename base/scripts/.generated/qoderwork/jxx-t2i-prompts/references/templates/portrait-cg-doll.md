# 3D 瓷感人偶肖像

高端风格化写实：材质（瓷/树脂）+ 发丝 + 边缘高光 三件套，情绪靠垂眼与浅景深。

## 完整示例

高精度 3D 数字人偶风格 CG 人像，一位二十出头的东方女性，微微低头，眼睑轻垂，神情安静克制、轻微出神，嘴唇自然放松，皮肤为半透明瓷感高级 CG 材质，头发有真实发丝质感，暖色自然光从一侧偏上方照来，重点照亮头顶一侧与发丝边缘形成柔和金色透光和边缘高光，脸部局部受光局部留影，浅景深背景虚化，轻微体积雾与柔和辉光，唯美空灵朦胧，电影化。

## 调参备注

- 「瓷感」与「塑料感」一线之隔：加次表面散射（subsurface scattering）和发丝透光，去掉任何「光泽油亮」。
- 眼睑轻垂比直视更出质感；直视会变证件照。
- 需要更「手办」就换成 miniature figurine, studio lighting, 并加台座描述。
