# 复古胶片 35mm 人像

胶味 = 宽容度高光 + 颗粒 + 轻微偏色 + 抓拍构图。别写「复古」就完事。

## 骨架

[年代 + 城市], [人物 + 穿搭], [动作], [胶片与镜头], [光线], [扫描质感], [构图]

## 模块词库

| 模块 | 关键词示例 |
| --- | --- |
| 年代城市 | 1990s Tokyo street, Paris 1980s cafe, Hong Kong 90s alley |
| 人物穿搭 | vintage denim jacket, slip dress, oversized sunglasses |
| 动作 | candid mid-step, lighting a cigarette, laughing with eyes closed |
| 胶片镜头 | shot on Kodak Portra 400, 35mm lens, f/2, slight motion blur |
| 光线 | overcast daylight, window backlight, soft flare |
| 扫描质感 | film grain, halation on highlights, slight color shift, dust specks |
| 构图 | candid framing, off-center, imperfect horizon |

## 完整示例

90 年代东京街头胶片人像，20 多岁女性，复古丹宁外套配吊带裙，抓拍她迈步回头的瞬间，阴天柔光，35mm 镜头 f/2，Kodak Portra 400，胶片颗粒，高光有轻微光晕，颜色略偏青绿，画面有零星灰尘划痕，构图偏一侧、地平线略斜，真实抓拍感。

## 英文版示例

1990s Tokyo street film portrait, woman in her twenties, vintage denim jacket over a slip dress, candid mid-step glance back, overcast soft daylight, 35mm lens, f/2, shot on Kodak Portra 400, visible film grain, halation on highlights, slight green-cyan color shift, dust specks and faint scratches, off-center framing with a slightly tilted horizon, true candid feel

## 负面提示词

digital sharpness, hdr, plastic skin, perfect symmetry, studio lighting, watermark, text

## 调参备注

- 「halation（光晕）」是胶味关键，比 grain 更能区分数码。
-  imperfections 要留：写 imperfect framing / dust specks；磨得太干净就成数码片。
- 想要更老再加 soft focus + vignette，但两者同时开会糊脸。
