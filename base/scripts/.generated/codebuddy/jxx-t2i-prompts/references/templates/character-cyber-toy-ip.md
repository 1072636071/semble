# 赛博机能潮玩 IP

不是人像，是 IP 形象：品牌名 + 品类 + 风格 + 色值 + 材质 + 机能件。

## 骨架

[品牌/命名], [物种与形态], [主色（色值）], [材质], [机能件], [光效], [整体风格]

## 模块词库

| 模块 | 关键词示例 |
| --- | --- |
| 品牌命名 | 潮玩品牌 "ZORA" 吉祥物设计 |

## 完整示例

潮玩品牌 "ZORA" 吉祥物设计：趣味潮流加赛博朋克风。紫色机械萌兔（#9B59B6），金属质感兔耳，眼部搭载荧光绿 LED 光效，头戴银色机能风护目镜，哑光与磨砂外壳混搭金属反光，潮玩手办质感的立体造型，纯色背景。

## 调参备注

- 色值写十六进制能锁住品牌色；写「紫色」每次都不一样。
- 「潮玩手办感」比「赛博朋克」更能压住画面，别只写后者。
- 同系列换物种（兔/柴犬/刺猬/猫）即得一套 IP 家族，骨骼描述不动。
