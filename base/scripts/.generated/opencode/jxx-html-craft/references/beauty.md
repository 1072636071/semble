# beauty.md — 视觉系统

质量底线之上的美学要求。目标是"看起来被人设计过"，每个文件一个完整的视觉世界。

## 先定世界，再写代码

动手前先在心里回答四个问题，答案决定所有样式：

1. **谁看**：开发者看报告？领导看汇报？客户看方案？——决定克制还是表现。
2. **在哪看**：白天办公室、暗色机房、手机上转发？——决定明暗与对比基调。
3. **什么情绪**：数据严谨、产品活力、文档安静？——决定色板与圆角。
4. **一个记忆点**：这个页面让人记住什么？一个超大数字、一个独特色、一个精心排版的开头。每页留一个"我特意做了这里"的瞬间。

## 排版

- 自建字阶，比例 1.25（小页面）或 1.333（大页面）：如 13 / 16 / 20 / 25 / 31 / 42px。
- 正文行高 1.6–1.8，中文取上限；标题行高 ≤1.2。
- 段落宽度 65–75ch；全宽文本墙是灾难。
- 标题字距 -0.02em 到 -0.03em（不要超过 -0.04em）；正文不调字距。
- 数字数据用 `font-variant-numeric: tabular-nums` 对齐。
- 字体层级用**字重 + 字号**做对比，同一页面最多两个字族。

## 配色

- 60-30-10：60% 主背景、30% 次级表面、10% 强调色。
- 一切颜色从一个主色派生（HSL 调 L 和 S），不要东拼西凑拾色器颜色。
- 深浅文字都在主色系内衍生：深底用 `hsl(同H, 低S, 85%)`，不用纯灰 `#999`。
- 状态色（成功/警告/危险）全站统一语义，不复用强调色。
- 彩色背景上的文字一律实测对比度。

## 间距与布局

- 用 4px 或 8px 基准网格，间距全部是基准的倍数。
- 组内紧凑、组间宽松；**标题上方的留白大于下方**。
- 区块之间留白 ≥64px（桌面），宁可空不可挤。
- 卡片圆角 12–16px；小控件（按钮、标签）才用全圆角。
- 阴影只声明一次：宽而软的投影（`0 4px 24px rgba(0,0,0,.08)`）或 1px 边框，二选一，不叠用。

## 组件质感

- 按钮：实底主按钮 + 幽灵次按钮，hover 有反馈（亮度或位移），disabled 降透明度。
- 表格：表头与正文有色区分、斑马纹或分隔线二选一、数字右对齐 tabular-nums。
- 代码块：等宽字体仅用于代码/数据/命令，深底浅字，横向可滚动。
- 图标：来自一个真实图标库（内联 SVG），统一线宽与风格；不用 emoji 当图标。

## 动效

- 每页一个"主笔瞬间"（hero 数字滚动、图表生长、标题浮现），其余元素至多统一入场的淡入上移。
- 缓动用指数缓出：`cubic-bezier(0.16, 1, 0.3, 1)`；时长 300–600ms。
- 动 transform/opacity/filter，不动 layout 属性。
- `@media (prefers-reduced-motion: reduce)` 全部关停。

## 反模式（出现即重写）

- 浏览器默认样式的链接蓝 `#0000EE` 和 Times 正文。
- 彩虹渐变文字、玻璃拟态滥用、装饰性 backdrop-blur。
- 卡片上 >1px 的彩色左边框（callout 除外，且需有真实语义）。
- emoji 顶替图标体系、等宽字体顶替"技术感"。
- 所有卡片同尺寸 icon+标题+正文三件套铺满页面——卡片是懒容器。
- 标题上方加 eyebrow/kicker 小标签（"OUR SERVICES" 之类）——标题自己撑得住。
- 硬偏移阴影 `box-shadow: 4px 4px 0`（除非整页真的是新粗野主义世界）。
- 渐变横幅/彩条当页面骨架——装饰要有来处（主题世界），不是默认动作。
