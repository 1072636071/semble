# 产品商业广告

主体 = 产品本身；成败在「材质 + 光位 + 台面」。

## 骨架

[产品 + 品牌感], [材质与工艺细节], [核心卖点可视化], [构图与台面], [光位], [背景/环境], [画质与后期]

## 模块词库

| 模块 | 可用词 |
| --- | --- |
| 产品 | 极简香水瓶，哑光金属机械键盘，透明玻璃瓶装精华液，陶瓷咖啡杯 |
| 材质细节 | 磨砂玻璃，拉丝金属，水珠凝结，皮革缝线，logo 压印 |
| 卖点可视化 | 一滴液体悬空，烟雾环绕，剖面展示内部结构，使用场景手持 |
| 构图台面 | 居中特写，45 度俯拍，大理石台面，水面倒影，亚克力展台 |
| 光位 | 侧逆光勾边，柔光箱，条形光反射在金属上，硬光投影 |
| 背景 | 纯色背景 / 渐变灰 / 低饱和环境色，虚化道具 |
| 画质后期 | 商业产品摄影，8K，锐利细节，干净背景，无水印 |

## 完整示例

极简香水瓶产品广告，磨砂玻璃瓶身带金属瓶盖，瓶身挂有水珠，居中特写置于水面亚克力台面上方，倒影清晰，侧逆光勾出瓶身轮廓，背景为低饱和渐变灰，虚化绿植点缀，商业产品摄影，8K 超清，锐利细节，干净背景。

## 负面提示词

text, watermark, logo distortion, cluttered background, dirty surface, plastic look, blown highlights

## 调参备注

- 产品文字/logo 必崩（多数模型）→ 提示词里不要要求具体文字，留白后期排版。
- 想要「高级感」→ 减道具、加负空间：`minimal composition, lots of negative space`。
- 电商主图 → 补 `white background, centered, product only`；氛围图 → 补场景与人物手部。
