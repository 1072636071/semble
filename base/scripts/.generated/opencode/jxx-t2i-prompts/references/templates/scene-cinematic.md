# 电影感场景 / 氛围图

先定「一个瞬间」，再挂镜头与光。

## 骨架

[时间 + 地点 + 天气], [主体或视觉锚点], [中景与远景层次], [镜头与视角], [光线与大气], [色调], [画质]

## 完整示例

黎明前薄雾笼罩的山脊，一座孤灯小屋作为视觉锚点，前景虚化的草叶，远景层叠山峦与大气透视，24mm 广角低机位，逆光穿雾形成丁达尔光柱，低饱和青橙色调，电影感宽画幅 2.39:1，胶片颗粒，通透画质。

## 负面提示词

oversaturated, cluttered, hdr过度, plastic look, low detail, warped horizon, floating objects

## 调参备注

- 空景容易平淡 → 加人类尺度锚点：`tiny figure for scale, single light source`。
- 想要「故事感」→ 把一句话事件写进主体格：`a lone traveler pausing to look back`。
- 宽画幅非所有平台支持 → 用参数（如 `--ar 21:9`）而不是只靠文字。
