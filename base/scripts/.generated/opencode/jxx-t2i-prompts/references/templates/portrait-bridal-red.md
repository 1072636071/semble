# 婚纱写真（红裙）

写真的模块化写法：服装 / 妆容 / 发型 / 场景 / 姿势 / 画质风格 六段，加「第一人称视角 + 前景虚焦」出亲密感。

[服装], [妆容], [发型], [场景与道具], [姿势与视角], [画质与风格], [比例]

## 完整示例

服装：红色高定抹胸婚纱，带精致蕾丝边和珍珠装饰，裙摆为渐变红白色层层堆叠的超蓬松大裙摆，有细腻光泽。妆容：冷白哑光底妆，微珠光眼影，纤细上扬的黑色眼线，根根分明的睫毛，橘红色腮红轻扫脸颊，镜面复古红唇，面部细微高光。发型：黑色长卷发编发，点缀红色丝带蝴蝶结，慵懒随意。场景：复古欧式奢华室内，复古钢琴、金色烛台、水晶灯、壁炉与大量红橙色系鲜花，一棵挂满小饰物的圣诞树与堆叠的红色礼盒。姿势：第一人称视角，仿佛她正递出一份包装精美的圣诞礼物，伸出一只手，脸在前景中可见，带着温暖微笑，轻微失焦。画质：雪花飘落，光线落在人物身上，梦幻浪漫，电影质感胶片摄影，朦胧诗意，独特颗粒感，虚焦氛围，高清晰度真人写真。比例 2:3。

## 调参备注

- 六段结构照抄，别合并——写真馆质感的秘密是「每段都有具体物」。
- 第一人称视角是差异点；写成「站在她对面」会退回普通构图。
- 手是最容易崩的一格：加「手部自然放松」并在负面里封手指。
