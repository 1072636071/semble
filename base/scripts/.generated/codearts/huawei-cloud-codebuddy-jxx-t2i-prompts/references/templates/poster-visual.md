# 海报 / 主视觉

模型排不好字：**出视觉、留字位、文字后期**。

## 骨架

[主题 + 情绪], [主视觉图形/主体], [构图与留白（字位）], [色彩体系], [质感与工艺], [风格参考], [画幅]

## 模块词库

| 模块 | 可用词 |
| --- | --- |
| 主题情绪 | 音乐节，科技发布会，电影悬疑片，中秋礼盒 |
| 主视觉 | 巨大半透明球体，破碎几何形状，人物剪影，放射状光 |
| 构图留白 | 上方 1/3 大面积留白放标题，中心对称，对角构图 |

| 质感工艺 | 丝网印刷颗粒，金属烫印反光，纸张纹理，磨砂半透明 |
| 风格参考 | 瑞士国际主义，粗野主义，复古波普，极简高端 |
| 画幅 | 竖版 3:4 海报，方版，宽幅横版 |

## 完整示例

科技发布会主视觉海报，巨大半透明球体悬于纯黑空间，光线从球体内部放射，上方三分之一大面积留白用于标题，黑金配色，磨砂半透明质感与细颗粒，极简高端风格，竖版 3:4 构图。

## 负面提示词

gibberish text, distorted letters, fake typography, cluttered layout, watermark, low contrast

## 调参备注

- 任何平台要求「写出标题文字」都会得到乱码 → 提示词只说 `space for title`，文字用 HTML/PS 后期排。
- 需要真文字 → 改用支持文字渲染的模型，或走本地版式工具。
- 系列化 → 固定「构图与留白 / 色彩」两格，只换主视觉。
