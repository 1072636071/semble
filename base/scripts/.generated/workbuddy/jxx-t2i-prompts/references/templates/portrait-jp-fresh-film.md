# 日系清新胶片

万能公式：主体 + 动作/状态 + 环境 + 光线 + 风格 + 构图/镜头。灵魂三个词：过曝、胶片、富士。

## 骨架

[主体 + 年龄 + 造型], [动作/状态], [环境], [光线], [风格与色调], [构图/镜头]

## 模块词库

| 模块 | 关键词示例 |
| --- | --- |
| 主体造型 | 18 岁女生，双马尾，JK 制服 / 白衬衫 + 百褶裙 |
| 动作状态 | 站在樱花树下回头，微风拂发，低头看书，坐在台阶上 |
| 环境 | 樱花道，日式街道，海边防波堤，教室窗边 |
| 光线 | 柔和自然光，逆光，午后侧光，轻微过曝 |
| 风格色调 | 日系胶片色调，富士相机风格，低对比，淡青绿 |
| 构图镜头 | 中景，浅景深，35mm，半身偏下留白 |

## 完整示例

一个 18 岁的女生，扎着双马尾，穿 JK 制服，站在樱花树下，微风吹过花瓣飘落，柔和自然光，轻微过曝处理，日系胶片色调，富士相机风格，中景半身，浅景深。

## 英文版示例

an 18-year-old girl with twin tails in a JK school uniform, standing under a cherry tree, petals drifting in the breeze, soft natural light, slightly overexposed, Japanese film color grade, Fujifilm look, medium shot, shallow depth of field

高饱和, 强对比, 塑料皮肤, 3d 渲染, 过度锐化, 文字, 水印

## 调参备注

- 「过曝」是这套的关键，且要轻：写「轻微过曝」；写死「过曝」会白掉。
- 平台换 MJ 时把「富士相机风格」写成 shot on Fujifilm, film simulation，过曝用 slight overexposure。
- 想要更「日本电影」就加具体机位：低机位、逆光、镜头光晕。
