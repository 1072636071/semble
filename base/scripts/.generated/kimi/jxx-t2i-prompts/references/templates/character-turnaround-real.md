# 写实三视图人物设定

给建模/短剧用：画质封顶 + 人物精准定参 + 视角排版 + 硬约束。笼统词（长发、红衣、瘦高）一律禁止。

## 骨架

[画质封顶], [人物精准定参：年龄/脸型/五官/发型/身形], [服装与配饰], [站位与排版], [一致性硬约束], [背景]

## 模块词库

| 模块 | 关键词示例 |
| --- | --- |
| 画质封顶 | 8K 超高清，极致细节，电影级柔和光影，全局对焦，无畸变，商用级人物设定稿 |
| 人物定参 | 25 岁，鹅蛋脸，高鼻梁浅杏眼，温柔神态，深棕色高马尾长发，碎发修饰脸型，身形纤细匀称 |
| 服装配饰 | 简约白色通勤衬衫，黑色高腰西裤，银色细项链 |
| 站位排版 | 站姿笔直自然；三格排版：正面平视、标准侧视、背面平视，人物大小比例统一 |
| 一致性约束 | 三视图所有五官、发型、服饰、配饰、色彩 100% 一致，无细节错乱，无角度偏移，构图规整 |
| 背景 | 纯白干净背景 |

## 完整示例

8K 超高清，极致细节，电影级柔和光影，全局对焦，无畸变，商用级人物设定稿，纯白干净背景。同一青年女性，25 岁，鹅蛋脸，高鼻梁浅杏眼，温柔神态，深棕色高马尾长发，碎发修饰脸型，身形纤细匀称，身穿简约白色通勤衬衫与黑色高腰西裤，银色细项链配饰，站姿笔直自然。画面三格排版：正面平视、标准侧视、背面平视，人物大小比例统一，三视图所有五官、发型、服饰、配饰、色彩细节完全一致，无细节错乱，无角度偏移，构图规整，高清全身立绘。

## 负面提示词

模糊描述, 角度偏移, 三视图不一致, 背景杂乱, 畸变, 多余肢体, 文字, 水印

## 调参备注

- 三视图仍常只出一个视角：多数模型需跑 2-3 张挑，或分三次生成再拼。
- 服装写「颜色 + 版型 + 材质」，禁「红衣」这类笼统词——这是原教程点名的坑。
- 要进建模管线再加 T-pose、对称、蓝图标注。
