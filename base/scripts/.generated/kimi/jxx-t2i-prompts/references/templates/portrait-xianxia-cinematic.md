# 古装仙侠电影感

小说封面/海报路数：主体 + 服装 + 动作 + 环境 + 光线 + 风格 + 镜头，镜头语言必须写。

## 骨架

[人物 + 身份], [服装], [动作/兵器], [环境], [光线与天气], [神情气质], [风格定位], [镜头]

## 模块词库

| 模块 | 关键词示例 |
| --- | --- |
| 人物身份 | 18 岁女剑修 / 贵妃 / 隐世仙子 |
| 服装 | 白色长袍 + 银色腰封；石榴红齐胸襦裙 + 泥金披帛 |
| 动作兵器 | 手中长剑半出鞘；手执鎏金酒壶斜倾；衣带被风吹起 |
| 环境 | 云海山门石阶，远处群峰如剑；海棠树下花瓣纷落；重檐楼阁铜铃 |
| 光线天气 | 清晨薄雾与金色日光穿云；月影 + 烛光双光源 |
| 神情气质 | 眼神冷静坚定，清冷高贵；眼神迷离含笑，酒意酣然 |
| 风格定位 | 古风仙侠小说封面，电影感人像 |
| 镜头 | 低角度仰拍 / 中景 / 浅景深 |

## 完整示例

一位 18 岁中国女剑修，白色长袍配银色腰封，黑色长发被山风吹起，站在云海山门前的石阶上，手中长剑半出鞘，远处群峰如剑，清晨薄雾与金色日光穿过云层，眼神冷静坚定，气质高贵克制，古风仙侠小说封面，电影感人像，低角度仰拍，浅景深。

## 英文版示例

an 18-year-old Chinese female immortal sword cultivator, white robe with silver sash, long black hair lifted by mountain wind, standing on stone steps before a gate above a sea of clouds, sword half drawn, distant peaks shaped like blades, morning mist and golden sunlight breaking through clouds, calm resolute gaze, restrained noble aura, xianxia novel cover, cinematic portrait, low angle shot, shallow depth of field

## 负面提示词

现代服装, 卡通, 畸变肢体, 多条手臂, 文字, 水印, 过曝

## 调参备注

- 镜头格不写就出「站着的证件照」：低角度仰拍 + 环境占比是电影感来源。
- 兵器与手部一起崩 → 让剑半出鞘、手只露一部分，或手出画。
- 双光源（冷月 + 暖烛）比均匀补光更有戏；写清哪个光源打脸。
