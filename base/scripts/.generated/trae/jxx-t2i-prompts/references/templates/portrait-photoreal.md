# 写实人像摄影

把人像写成「一张真实拍出来的照片」：镜头语言压过风格词。

## 骨架

[拍摄对象 + 年龄气质], [面部与皮肤细节], [发型/妆造], [服装], [姿态与视线], [场景与环境], [镜头参数 + 光线], [后期质感]

关键：**镜头参数是主要抓手**（焦段、光圈、光位），风格词是次要。

## 模块词库

| 模块 | 可用词 |
| --- | --- |
| 拍摄对象 | 28 岁东亚女性，清冷知性气质；35 岁东亚男性，胡茬，沉静 |
| 面部细节 | 自然妆容，可见毛孔与细纹，皮肤质感真实，眼神光，唇纹 |
| 发型妆造 | 微卷中长发，碎发被风吹起，湿发造型，淡妆 |
| 服装 | 米色针织衫，白色衬衫，亚麻西装，极简无 logo |
| 姿态视线 | 侧脸看向窗外，手扶杯沿，低头浅笑，抓拍自然 |
| 场景环境 | 清晨咖啡馆窗边，老城区巷口，雨后街面反光，极简白墙 |
| 镜头参数 | 85mm f/1.4，浅景深，背景虚化；35mm 环境人像；eye-level 平视；侧逆光 + 柔光补光 |
| 后期质感 | 胶片颗粒，Kodak Portra 400 色调，轻微高光溢出，肤色自然不磨皮 |

## 完整示例

28 岁东亚女性，清冷知性气质，自然妆容，皮肤可见真实毛孔与细纹，眼神有光，微卷中长发几缕碎发垂落，穿米色针织衫，侧身坐在清晨咖啡馆窗边低头浅笑，背景虚化可见暖光与书架，85mm f/1.4 拍摄，浅景深，侧逆光加柔光补光，胶片颗粒，Kodak Portra 400 色调，真实摄影质感。

## 负面提示词

plastic skin, airbrushed, oversmooth, doll-like, extra fingers, deformed hands, watermark, text, oversaturated, hdr halo

## 调参备注

- 出来像 3D 或插画 → 前置 `raw photo, photograph`，加 `shot on Sony A7R IV`。
- 皮肤塑料感 → 负面上 `airbrushed, beauty filter`，正面补 `visible skin texture, pores`。
- 手部畸形（含手的姿势最容易崩）→ 换姿势避开手，或后期只留 `hands out of frame`。
