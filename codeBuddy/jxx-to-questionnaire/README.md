# jxx-to-questionnaire

当计划或决策需要的答案 agent 给不出、而持有答案的是别人时，将对话转化为措辞中立的问卷，交给对方填写——这样你就不用反复当传声筒。

## 何时使用

- 答案在客户、经理、安全团队、其他部门手上，不在当前对话的人手上。
- 未决决策需要外部输入，且一次问清比来回沟通更高效。
- 让"持有答案的人"直接作答，而非靠转述。

## 流程

1. 收集未决决策，每个成为问卷中的一节。
2. 按 B 的心智模型分组，而非按你的。
3. 写清每个问题需要怎样的答案。
4. 留出作答空间（`**答：**`）。
5. 交给 B 填写，带答案返回。

## 问卷回来之后

通读答案：解决的决策更新计划；引出的新分支进入下一轮 grill 或跟进问卷。带答案的问卷成为该决策的记录。

## 相关技能

- `/jxx-grilling` — 新分支的下一轮追问
