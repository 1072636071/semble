# jxx-wizard

生成一个交互式 bash 向导，引导人完成手动多步流程——在 Web 控制台里点来点去、创建账号、生成密钥、配置 OAuth、打开开关。

## 何时使用

- 有人必须执行手动多步流程，agent 无法代劳（Web 控制台、注册表单、密钥生成、OAuth 授权）。
- 步骤超过约 3 个，或某一步产出的值是后续步骤的输入。
- 出错概率高，希望每个值都被捕获而不是丢在聊天记录里。

## 如何构建

复制 `template.sh` 到仓库合适位置，只编辑 `STAGES` 标记以下的部分。每个 stage 是一个人做的步骤，内部用 `say`/`step`/`open_url`/`ask`/`ask_secret`/`confirm` 等原语。将 `TOTAL_STAGES` 设为实际 stage 数。

## 构建之前

1. 走完真实流程（每个 URL、按钮、字段标签必须正确）。
2. 决定值的去向（`.env` / GitHub 密钥）。
3. 保持 stage 原子化（一个 stage = 一个概念性步骤）。

## 反模式

- 不要为 agent 能自动化的步骤写向导（`curl` 或 `gh api` 能做到的就那样做）。
- 不要把密钥打进聊天或日志。
- 不要捕获用户已有文件的值。
