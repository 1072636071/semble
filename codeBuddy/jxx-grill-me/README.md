# jxx-grill-me

启动 `/jxx-grilling` 会话，对计划或设计进行穷追不舍的 grill 追问以打磨方案。用于**不在工作目录中工作**的场景（无状态，不构建 `CONTEXT.md`）。

## 何时使用

- 用户想要 review 计划、澄清设计或提到"grill"时。
- 在**不在工作目录中工作**时打磨计划或设计。

## 输入 / 输出

- **输入**：用户的计划或设计（对话中直接提供）。
- **输出**：`/jxx-grilling` 会话产出的逐条追问记录与共同确认后的方案。

## 相关技能

- `/jxx-grilling` — 实际执行 grill 追问的原语
- `/jxx-grill-with-docs` — 在工作目录中工作时（会留下文档记录）的版本
