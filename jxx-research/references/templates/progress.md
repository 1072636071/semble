# progress — 项目进度报告

用于项目状态汇报、迭代回顾、里程碑总结。

## 标准节

| 节 | 必填 | 内容 |
| -- | ---- | ---- |
| **摘要** | 是 | 当前阶段概述、整体进度百分比、关键里程碑状态 |
| **当前状态** | 是 | 一句话：项目处于什么阶段（规划/开发/测试/上线/维护） |
| **已完成项** | 是 | 本期完成的功能、修复、优化，每项一句话 |
| **进行中项** | 是 | 正在做的工作，预计完成时间 |
| **阻塞与风险** | 是 | 当前卡点、潜在风险、需要协调的资源 |
| **指标** | 否 | 关键数据：代码量、Bug 数、测试覆盖率、性能基准 |
| **下一步计划** | 是 | 下个周期的目标和优先级 |
| **时间线** | 否 | 关键节点的日期对照（计划 vs 实际） |

## 示例场景

- "汇总 Q2 前端团队工作进展"
- "整理本周 Sprint 回顾报告"
- "汇报 v2.0 里程碑达成情况"
