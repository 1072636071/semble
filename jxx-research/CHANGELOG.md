# Changelog

## 2.2.0 — 2026-07-30

严格模式抽离到独立文件。

- 新增 `references/strict-mode.md`，包含严格模式的完整工作流（5 阶段）、输出位置、模板选择、完成标准、专属护栏和反模式
- SKILL.md 精简为：模式选择、自由模式、通用护栏（两种模式共用）、通用反模式
- 严格模式相关内容从 SKILL.md 完全移除，通过链接引用

## 2.1.0 — 2026-07-30

双模式架构：自由模式（默认）+ 严格模式。

- 新增自由模式：不规定流程，agent 自主决定调研方式和输出，保留来源可追溯纪律
- 严格模式即 v2.0.0 的完整工作流，触发词：生成报告/严格模式/按模板
- 模板拆分为独立文件：`references/templates/{tech,progress,analysis,general}.md`
- 删除旧的合并模板文件 `references/report-templates.md`

## 2.0.0 — 2026-07-30

重大增强：从纯调研技能升级为调研+报告生成技能。

- 新增结构化报告生成能力，输出到 `docs/report/`
- 新增 4 套报告模板（tech / progress / analysis / general）
- 新增 5 阶段工作流：明确目标 → 选择模板 → 多源调研 → 整理生成 → 交付
- 新增冲突处理机制（同名文件不覆盖，创建新文件并告知差异）
- 新增模板参考文件 `references/report-templates.md`
- 强化来源可追溯纪律（区分事实 vs 推断）
- 新增完成标准、护栏、反模式

## 1.0.0 — 2026-07-06

初始版本，翻译自 mattpocock/skills。
