# 中文 AI 写作痕迹模式库

> 收录中文场景下 LLM 写作的高频模式与改写对照。模式分两大类：**A. 词面触发**（自动化脚本能识别）**B. 结构/语义触发**（需要人工或模型识别）。

---

## A 类 · 词面触发（自动化可扫描）

### A1 · 开头套话（开头即扣分）

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 在当今社会 / 在当今时代 | ⭐⭐⭐ | 直接删除或换成具体场景 |
| 随着 XX 的发展 / 近年来，XX 日益 | ⭐⭐⭐ | 用具体时间替代 |
| 众所周知 / 毋庸置疑 / 不可否认 | ⭐⭐⭐ | 删除或换成"大部分人都……" |
| 伴随着 XX 的快速发展 | ⭐⭐⭐ | 改为"XX 出现后" |
| 在 XX 的背景下 | ⭐⭐ | 改为具体语境 |
| 一直以来，XX 都 … | ⭐ | 改为"过去几年" |

**改写前 → 改写后：**
> 在当今社会，人工智能技术日益发展，众所周知已经渗透到各行各业。
> → AI 已经渗到各行各业。从客服到代码生成，几乎没有它不碰的角落。

---

### A2 · 转折/连接词滥用

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 此外 / 与此同时 / 不仅如此 | ⭐⭐ | 句子直接接上，或用句号断开 |
| 然而 / 但是 / 尽管如此 | ⭐ | 多用句号分段，靠上下文连接 |
| 因此 / 综上所述 / 总而言之 | ⭐⭐ | 删除，结论直说 |
| 一方面…另一方面… | ⭐⭐ | 拆成两段 |
| 既…又…还… | ⭐⭐ | 拆成两个动作 |
| 无可厚非 / 瑕不掩瑜 | ⭐⭐⭐ | 删除套话 |

**改写前 → 改写后：**
> 这一举措不仅提升了效率，此外还降低了成本。总而言之，效果显著。
> → 效率提上来了，成本也降了不少。

---

### A3 · 形容词堆砌 / 官腔

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 至关重要 / 举足轻重 / 不可或缺 | ⭐⭐⭐ | 删除或换具体作用 |
| 深入探讨 / 深入分析 / 深入研究 | ⭐⭐⭐ | 改为"看一下"、"聊聊" |
| 核心 / 关键 / 精髓 / 要义 | ⭐ | 多数情况可删 |
| 高效 / 便捷 / 智能化 / 数字化 | ⭐ | 换成具体数字 |
| 高度重视 / 深入推进 / 扎实开展 | ⭐⭐⭐ | 改为"认真做了" |
| 积极探索 / 有效落实 / 持续优化 | ⭐⭐⭐ | 删除 |
| 凝聚共识 / 汇聚合力 / 协同推进 | ⭐⭐⭐ | 删除 |
| 全方位 / 多角度 / 立体化 / 全链路 | ⭐⭐ | 删除或具体化 |

**改写前 → 改写后：**
> 我们高度重视用户体验，深入推进产品优化，全方位提升服务质量。
> → 我们改了改界面，把加载从 3 秒压到 800 毫秒。

---

### A4 · 结尾升华

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 让我们共同 / 让我们一起 | ⭐⭐⭐ | 删除或改成具体行动 |
| 未来可期 / 任重道远 | ⭐⭐⭐ | 删除 |
| 在 XX 的道路上不断前行 | ⭐⭐⭐ | 删除 |
| 为 XX 贡献力量 / 谱写新篇章 | ⭐⭐⭐ | 删除 |
| 砥砺前行 / 扬帆远航 | ⭐⭐⭐ | 删除 |
| 展望未来，XX 将 … | ⭐⭐ | 改为具体计划 |

**改写前 → 改写后：**
> 让我们共同期待，在数字化转型的道路上不断前行，谱写新篇章。
> → 下个季度重点做两件事：把审批从 1 天压到 2 小时，把月报改成周报。

---

### A5 · 排比 / 三段式 / 伪对仗

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| X、X 与 X / X、X、X | ⭐ | 多用两项或四项 |
| 一是…二是…三是… | ⭐⭐ | 改成自然过渡 |
| 既…又…还… | ⭐⭐ | 拆句子 |
| 这不仅…也…更… | ⭐⭐⭐ | 砍掉中间环节 |
| 从 X 到 Y，从 X 到 Y | ⭐⭐ | 删 |

**改写前 → 改写后：**
> 这不仅体现了技术创新的力量，也彰显了人文关怀的温度，更展示了企业文化的深厚底蕴。
> → 背后是技术团队和文化团队一起搭的。

---

### A6 · 营销体 / 互联网黑话

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 赋能 / 加持 / 引爆 / 破圈 | ⭐⭐⭐ | 改为具体动词 |
| 打造 / 构建 / 重塑 | ⭐⭐ | 看情况，多数可删 |
| 一站式 / 全链路 / 闭环 | ⭐⭐ | 改为具体描述 |
| 抓手 / 打法 / 颗粒度 | ⭐⭐⭐ | 删除或换说法 |
| 底层逻辑 / 顶层设计 | ⭐⭐⭐ | 删除 |
| 沉淀 / 拉通 / 对齐 | ⭐⭐ | 改为大白话 |

**改写前 → 改写后：**
> 我们致力于打造一站式全链路解决方案，赋能业务增长。
> → 我们做了一个工具，把 5 个流程合到一个页面上。

---

### A7 · 模糊归因 / 假权威

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 专家指出 / 业内人士表示 | ⭐⭐⭐ | 给具体名字 + 出处 |
| 据相关研究表明 / 大量数据表明 | ⭐⭐⭐ | 给出具体研究/数字 |
| 有学者认为 / 专家普遍认为 | ⭐⭐⭐ | 删除或具体化 |
| 众所周知 / 大家普遍认为 | ⭐⭐ | 删除 |

**改写前 → 改写后：**
> 专家指出，AI 在医疗领域具有广阔的应用前景。
> → 斯坦福 2024 年的报告显示，AI 辅助诊断在皮肤癌识别上准确率比医生高 5 个百分点。

---

### A8 · 伪深度分析（"是 XX 的体现/证明/象征"）

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 这是 XX 的体现 / 证明 / 象征 | ⭐⭐⭐ | 直接说事实 |
| 彰显了 XX 的意义 / 凸显了 XX 的价值 | ⭐⭐⭐ | 删除 |
| 反映了更深层次的 XX | ⭐⭐⭐ | 删除 |

**改写前 → 改写后：**
> 这一举措深刻体现了以人民为中心的发展思想，彰显了 XX 精神。
> → 这个改动就是为了让群众少跑一趟。

---

### A9 · 假大空成语串

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 博大精深 / 源远流长 / 历久弥新 | ⭐⭐⭐ | 删除或说人话 |
| 与时俱进 / 开拓创新 / 锐意进取 | ⭐⭐⭐ | 删除 |
| 举世瞩目 / 举世无双 | ⭐⭐⭐ | 删除 |

**改写前 → 改写后：**
> 中华文化博大精深、源远流长，历久弥新，与时俱进。
> → 这门手艺传了 200 年。

---

### A10 · 模板化口语痕迹

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 大家好，我是 XX | ⭐⭐⭐ | 删除 |
| 本文将从 XX 个方面进行阐述 | ⭐⭐⭐ | 直接进入第一点 |
| 希望本文能够对您有所帮助 | ⭐⭐⭐ | 删除 |
| 以上就是 XX 的全部内容 | ⭐⭐⭐ | 删除 |
| 如有疏漏，欢迎指正 | ⭐⭐⭐ | 删除 |
| 感谢您的观看 / 感谢阅读 | ⭐⭐⭐ | 删除 |

## B 类 · 结构/语义触发（人工或模型识别）

### B1 · 句式单一化

- 每个段落长度几乎相同
- 每段以"X。"短句机械收尾
- 全文都是"是 XX 的"结构
- 全文都是动宾结构（"提升 X、降低 Y、增强 Z"）

### B2 · 段落对称结构

- 全文每段都是"观点+论证+例子+总结"四件套
- 每一段都强行形成"总分总"

### B3 · 滥用标题层级

- 一段话一个标题，标题像"四字成语"
- 标题全部加 emoji 🚀💡✅
- 标题全部粗体加冒号

### B4 · 总结段落"放之四海而皆准"

- 结尾段像万能模板："未来还需继续努力，不断完善"
- 通用的三个"展望"项

### B5 · 缺乏具体细节

- 没有数字、时间、地点、文件名、版本号
- 全是抽象概念堆砌
- 没有真实的人名、公司名、产品名

### B6 · 缺乏个性化声音

- 没有"我"、"我们"的具体视角
- 没有不确定性表达（"我不太确定"、"可能"、"还在想"）
- 没有吐槽、自嘲、口语化断句
- 像新闻通稿 / 维基百科

### B7 · 标点滥用

- 过多破折号「——」
- 过多感叹号「！！！」
- 过多问号「为什么？为什么？为什么？」
- 中英混排但空格混乱（"iOS 设备""iOS设备"）

## C 类 · 中英夹杂警示

- 关键术语未给中文解释
- 一会儿用"用户"一会儿用"User"
- 中文为主但夹大段英文（典型 GPT 直出）

---

## D 类 · 与 humanizer-zh 的差异化补充

`humanizer-zh` 主要翻译英文版 Wikipedia 指南，对中文特色场景覆盖不足。本词库特别补强：

1. **官腔八股**（高度重视、深入推进、扎实开展）
2. **互联网黑话**（赋能、抓手、底层逻辑）
3. **四字成语串**（博大精深、源远流长）
4. **结尾升华段**（让我们、谱写新篇章）
5. **模糊归因**（专家指出、业内人士表示）
6. **模板化口水**（大家好、希望本文能够）

实际中文写作中，**官腔 + 互联网黑话 + 模板口水**这三类出现频率最高、读者最反感。
