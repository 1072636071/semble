# 中文 AI 味评分算法

> 0-100 分制，**100 分 = 完全人话**，**0 分 = 重度 AI 味**。模型可调整的扣分权重；脚本采用这套权重。

---

## 1. 总分公式

```
AI味指数 = max(0, 100 - Σ(各模式扣分) - 结构扣分 - 个性化缺失扣分)
```

**最低 0，最高 100。**

---

## 2. 词面模式扣分权重（每命中一次）

| 模式类别 | 单次扣分 | 上限 | 说明 |
|---|---|---|---|
| A1 开头套话 | -8 | -25 | 开头即扣，开头 200 字内权重 ×1.5 |
| A2 转折连接词 | -2 | -15 | 全文 |
| A3 形容词堆砌/官腔 | -4 | -25 | 全文 |
| A4 结尾升华 | -6 | -20 | 末段 200 字权重 ×2 |
| A5 排比/三段式 | -3 | -15 | 全文 |
| A6 营销体/黑话 | -5 | -25 | 全文 |
| A7 模糊归因 | -5 | -20 | 全文 |
| A8 伪深度 | -4 | -15 | 全文 |
| A9 假大空成语 | -3 | -12 | 全文 |
| A10 模板口水 | -5 | -20 | 开头/结尾权重 ×1.5 |
| C 中英夹杂 | -2/处 | -10 | 全文 |

**重复词叠加衰减**：同一词/短语在同一篇文章出现 N 次，扣分 = 单次扣分 × min(N, 3) — 防止低质量扫描"撑爆分数"。

---

## 3. 结构/语义扣分（人工或模型判断）

| 项目 | 扣分 | 判定要点 |
|---|---|---|
| 句式单一化 | -10 | 多于 5 个连续段落句式雷同 |
| 段落对称结构 | -8 | 每段都是"观点+例子+总结"模板 |
| 标题 emoji 滥用 | -3/个 | 每个标题/列表 emoji |
| 总结段落空泛 | -10 | 结尾段无具体数字/事实 |
| 缺乏具体细节 | -15 | 全文无数字、无名字、无时间 |
| 缺乏个性化声音 | -12 | 无"我/我们"视角、无不确定性表达 |
| 破折号过多 | -5 | 每 500 字 ≥ 3 个破折号 |
| 感叹号过多 | -3 | 全文 ≥ 3 个"！！！" |

---

## 4. 等级评定

| 分值 | 等级 | 含义 | 建议动作 |
|---|---|---|---|
| **85-100** | 🟢 人话 | 已读不出 AI 味 | 可直接发布 |
| **70-84** | 🟡 微 AI 味 | 有零星痕迹，不细看察觉不到 | 局部优化即可 |
| **50-69** | 🟠 中度 AI 味 | 一眼能看出"AI 写的" | 大改 1-2 段 |
| **30-49** | 🔴 重度 AI 味 | 满屏套话 | 重写或大刀阔斧改 |
| **0-29** | ⚫ 完全 AI 体 | 模板机器文 | 建议整段重写 |

## 5. 输出格式（标准化）

```markdown
## AI 味检测报告

**总分：** 32 / 100  🔴 重度 AI 味

### 分项评分
- 词面命中扣分：-45
- 结构问题扣分：-23
- **总计：-68 → 32 分**

### 命中位置（按严重度排序）
| # | 类别 | 命中内容 | 位置 | 严重度 |
|---|---|---|---|---|
| 1 | A4 结尾升华 | "让我们共同期待…" | 第 8 段 | 高 |
| 2 | A3 官腔 | "高度重视 / 深入推进" | 第 2-4 段各 2 次 | 高 |
| 3 | A6 营销体 | "赋能 / 一站式" | 第 3 段 | 中 |
| ... | | | | |

### Top 3 优先改写建议
1. **结尾段**（A4）：删掉"让我们…"句式，换成具体计划
2. **第 2-4 段**（A3）：官腔套话→大白话，参考 zh-patterns.md A3
3. **第 3 段**（A6）：营销体换具体动词

### 改写后复评
（重跑检测脚本，确认分数）
```

## 6. 检测脚本调用约定

```bash
# 单文件检测（输出 Markdown 报告到 stdout）
python3 scripts/scan_ai_flavor.py article.md

# 输出 JSON 供后续处理
python3 scripts/scan_ai_flavor.py --json article.md

# 指定输出文件
python3 scripts/scan_ai_flavor.py article.md -o report.md

# 管道输入
cat article.md | python3 scripts/scan_ai_flavor.py -
```
