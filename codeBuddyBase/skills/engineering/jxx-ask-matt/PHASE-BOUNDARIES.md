# 阶段边界

阶段边界是执行间隙：完成一个工单、复现了一个 bug、一个阶段关闭、一个 artifact 落地。你在边界处做的决定只有两个：**上下文**是否值得保留，以及**下一步**由谁来走。

选项自上而下按上下文保留度排序——**从顶部开始读，在第一个成立的停下**。`continue` 和 `/clear` 保留自包含的 artifact（plan、spec、调研文件）在原地；其余三个以不同的保真度把上下文带过去，用这个权衡来决定走多深。

## 决策树

- **下一步需要现在的上下文吗？** → **Continue**。写代码时对 spec 的讨论、调试时对失败的测试、grill 时对计划的讨论——下一阶段活在当前上下文里，任何转移方式都会丢失关键信息。
- **下一步是自包含的吗？** → `/clear` + 指向下一步。写在磁盘上的东西——spec、plan、代码本身——把全部上下文带走了；对话什么都没加。执行下一个工单、运行一个独立的 review pass、起一个新阶段——任何你本来就是从头开始的事。默认假设下一步是自包含的——真正的例外很少。
- **切换中的对话背景？** → `/handoff` 到目标 harness。跨机器、跨 harness、跨时间——要么继续对话，要么把工作带过去。
- **下一步有自己的上下文，但仍需要现在的上下文吗？** → **子 agent** 带着你提供的上下文去执行。
- **都不适用但上下文已经满了？** → `/compact`，在最近的阶段边界执行。

## Continue

成本为零。继续有代价的唯一时刻，是你把不再相关的上下文拖进了新工作。

## /clear

Plan 结束了。代码写完了。对话里没有任何下一步需要的东西。`/clear` 把上下文归零，下一步以一个新的对话开始，指向 plan。

`/clear` 不是丢弃工作——是丢弃对话。工作以 artifact 的形式存活：spec、plan、调研文件、代码。`/clear` 在 artifact 落地且指针存在时是正确的——文件路径、消息里的 URL、一行 "`/specs/auth-flow.md` 里的 spec"。清晰的指针意味着下一个对话立刻找到它；指针不在，就补上。

## /handoff

`/handoff` 捕捉**如何**到达这里——尝试过的方法、排除掉的方案、藏在对话里的决策理由。这只有在你自己就是那个上下文、而且对话还在继续时才值得付这个成本。

`/handoff` 也是 artifact——它把上下文写进文件，文件去哪都行。发到 Telegram，跨机器转移，带进另一个 harness，留到下周。

在 harness 内时优先选它而不是 `/compact`——信息无损，作为文件可引用、可转移、可携带。

## 子 agent

子 agent 带着**你提供的上下文**启动。你做计划，它去执行。

子 agent 也是 `/compact` 的替代品——把重的探索或实现分流到一个隔离的上下文，让主对话保持精简。

## /compact

`/compact` 原地压缩当前对话。它是快照，不是转移——你待在原地，上下文被压缩。

保留 `/compact` 给你*必须*继续、上下文已满是唯一问题的对话。即便这时，也优先 `/handoff`——信息无损，文件可引用、可转移、可携带。在最近的阶段边界执行 `/compact`：阶段中途压缩会丢失正在进行的推理。

## 主要来源 vs 次要来源

在阶段边界，以及一般的边界处，都会有同一个选择：是把上下文带过去（*次要*来源——浓缩版、handoff 文件、摘要），还是指向承载它的 artifact（*主要*来源——spec、plan、调研文件、代码本身）。两个视角决定这个选择：

- **谁需要它。** 人读次要来源——几分钟读完的摘要。agent 读主要来源——它们能消化完整 artifact，而且需要细节。问答循环里的 context pointer 指向主要来源；阶段边界的 handoff 浓缩成次要来源。
- **它要存多久。** 持久的上下文值得一个主要来源——你不会想从摘要里重建。临时的上下文只值得次要来源——不值得为它造一个 artifact。

|      | 主要                       | 次要                   |
| ---- | -------------------------- | ---------------------- |
| 指向 | 指向 spec 的 context pointer | 指向 handoff 的指针    |
| 携带 | 完整 artifact 文件          | `/compact`、对话摘要    |
