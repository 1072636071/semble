# 开发中

仍在开发中的技能。尚未准备好发布——预期有粗糙之处、破坏性变更和废弃实验。在晋升到稳定桶之前，它们不会出现在插件和顶层 README 中。

- **[loop-me](./jxx-loop-me/SKILL.md)** — 通过多轮 grill将自身打磨为可实施的工作流spec，跨多个会话进行，以当前目录作为有状态工作区。用户调用。
- **[wizard](./jxx-wizard/SKILL.md)** — 生成交互式 bash 向导，引导人类完成手动流程（安装配置、一次性迁移、状态转换）——打开 URL、采集值、写入 `.env` 和 GitHub Actions 密钥。用户调用。
- **[writing-beats](./jxx-writing-beats/SKILL.md)** — 以节拍旅程的方式塑造文章，类似选择你自己的冒险风格。选取起始节拍，只写该节拍，然后转向下一个，直到文章自然收尾。
- **[writing-fragments](./jxx-writing-fragments/SKILL.md)** — grill 会话，挖掘你的写作片段——异质的文字素材——追加到单个文档中，作为未来文章的原始材料。
- **[writing-shape](./jxx-writing-shape/SKILL.md)** — 取一份原始材料的 Markdown 文件，逐段塑造为文章，在每一步论证格式选择。
- **[claude-handoff](./jxx-claude-handoff/SKILL.md)** — 将当前对话交接给一个新的后台 agent，立即接手工作，通过 `claude --bg` 注入交接摘要。用户调用。
