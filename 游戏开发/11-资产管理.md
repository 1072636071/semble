# 资产管理（godot-asset-path-surgery）

> 修复文件夹迁移后二进制资源中硬编码的过期路径。

---

## 核心认知

Godot 资源携带两类路径信息：

| 类型 | 在哪 | 更新机制 |
|------|------|----------|
| **发现路径**（编辑器如何找到文件） | `.godot/uid_cache.bin`、`<file>.uid` | Godot 检测到文件移动时自动更新 |
| **内部 ExtResource 路径**（该文件引用谁） | 文件二进制负载内 | **不自动更新**，需 load() + save() 重写 |

文件夹迁移后：发现路径自动修复，但内部路径悄悄断开。症状：编辑器报红，游戏通常仍能运行，但错误面板被淹没。

---

## 决策树

```
编辑器显示: "Cannot open file 'res://<old-path>'"
│
├── 目标文件在新路径存在吗？
│   ├── No  → 真的删了，恢复或修引用
│   └── Yes → 继续
│
├── 错误来自二进制资源 (.mesh/.material/.scn/.res) 吗？
│   ├── No  → 纯文本 .tscn/.tres，sed 或 IDE 全局替换即可
│   └── Yes → 用下方手术模式（文件内部负载携带过期 UTF-8 字节）
│
└── 受影响的二进制是否还依赖另一个也移动了的资源？
    ├── No  → 模式 A（简单重保存）
    └── Yes → 模式 B（垫片 + 重新赋值 + 保存）
```

---

## 模式 A：简单重保存（自包含二进制）

**条件**: .mesh/.material/.scn 携带过期路径，但目标资源通过 UID 仍可访问。

```gdscript
# tools/resave_<thing>.gd
extends SceneTree

const PATHS := [
    "res://art/models/<new>/thing.mesh",
    "res://art/models/<new>/thing.material",
]

func _initialize() -> void:
    var failed := 0
    for p in PATHS:
        var res := ResourceLoader.load(p, "", ResourceLoader.CACHE_MODE_IGNORE)
        if res == null:
            push_error("[resave] load failed: %s" % p)
            failed += 1; continue
        # 强制内存 resource_path 匹配磁盘路径
        res.resource_path = p
        var err := ResourceSaver.save(res, p, ResourceSaver.FLAG_COMPRESS)
        if err != OK:
            push_error("[resave] save failed (%d): %s" % [err, p])
            failed += 1; continue
        print("[resave] ok: ", p)
    quit(0 if failed == 0 else 1)
```

运行：
```bash
godot --headless --quit --path . --script tools/resave_<thing>.gd
```

## 模式 B：垫片 + 重新赋值（ExtResource 断开的二进制）

**条件**: 二进制内部 ExtResource 路径过期，Godot 拒绝加载。

**策略**: 在旧路径临时放置目标副本 → 加载解析 → 重新指向新路径 → 保存 → 清理垫片。

```gdscript
extends SceneTree

const DEP_NEW := "res://art/models/<new>/material.material"
const DEP_OLD := "res://old/path/material.material"
const DEP_OLD_DIR := "res://old/path"
const BINARY := "res://art/models/<new>/mesh_with_dep.mesh"

func _initialize() -> void:
    # 1. 从真实路径预加载依赖
    var dep := ResourceLoader.load(DEP_NEW, "", ResourceLoader.CACHE_MODE_REUSE)
    if dep == null: push_error("cannot load dep"); quit(1); return

    # 2. 垫片：复制依赖到旧路径
    var da := DirAccess.open("res://")
    var old_dir_rel := DEP_OLD_DIR.replace("res://", "")
    if not DirAccess.dir_exists_absolute(ProjectSettings.globalize_path(DEP_OLD_DIR)):
        da.make_dir_recursive(old_dir_rel)
    da.copy(DEP_NEW, DEP_OLD)

    # 3. 加载二进制，重新赋值，保存
    var mesh := ResourceLoader.load(BINARY, "", ResourceLoader.CACHE_MODE_IGNORE) as ArrayMesh
    if mesh != null:
        for i in mesh.get_surface_count():
            mesh.surface_set_material(i, dep)
        mesh.resource_path = BINARY
        ResourceSaver.save(mesh, BINARY, ResourceSaver.FLAG_COMPRESS)

    # 4. 清理垫片
    da.remove(DEP_OLD)
    _remove_empty_parents_up_to_res(DEP_OLD_DIR)
    quit(0)
```

## 关键陷阱

### 长度不匹配破坏二进制 sed

```python
# ❌ 绝不这样做——文件被破坏
content = open(f, 'rb').read()
content = content.replace(b'level/textures/Material.material',
                          b'art/models/material.material')  # 新路径更长!
open(f, 'wb').write(content)
```

Godot 二进制资源将字符串编码为长度前缀（Pascal 风格）。新路径长度不同时，长度前缀失效，后续字段偏移 → 解析器崩溃。**始终通过 ResourceLoader/ResourceSaver 操作，绝不触碰原始字节。**

### 忘记 FLAG_COMPRESS

默认 save 写入未压缩（RSRC magic）。如果原始是压缩（RSCC），文件膨胀 3-5 倍。始终传 `ResourceSaver.FLAG_COMPRESS`。

### CACHE_MODE 选择

- **CACHE_MODE_IGNORE**: 从磁盘强制加载，用在你即将修改并保存的资源（避免修改编辑器缓存实例）
- **CACHE_MODE_REUSE**: 与编辑器缓存共享，用在依赖（希望其他引用继续指向它）

### .uid sidecar

任何新建 .gd 文件需要 .uid sidecar 才能提交。运行一次 `godot --headless --import --path .` 即可生成。

---

## 不适用此技能的情况

- **.tscn / .tres 文本资源**: 直接 sed 或 IDE 全局替换
- **UID 引用**: Godot 4 用 `uid://...` 标识符（位置无关），只需确保 `.godot/uid_cache.bin` 新鲜
- **1-2 个文件手动操作**: 文件少、用户熟悉编辑器时，直接在 FileSystem dock 右键 → Reimport / Save
