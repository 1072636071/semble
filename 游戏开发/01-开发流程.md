# Godot 开发流程

## 三场景分流（godot-dev 入口）

每次触发先跑环境探测，自动判定三个场景：

| 场景 | 条件 | 处理 |
|------|------|------|
| 场景1 `make_game` | 空环境，无项目 | godot-deploy（部署编辑器）→ godot-new（创建项目）→ 引导用户启用 MCP |
| 场景2 `new_game` | 已有编辑器，做新游戏 | 仅 godot-new（新建另一个项目目录，覆写 active-game.json） |
| 场景3 `modify_game` | 修改当前游戏内容 | 前置检查通过后，调用 `build_godot_scene` 一次性完成场景修改 |

## 完整开发五阶段

```
Phase 0: 需求收集     ──→ 问：类型/视角/平台/范围/参考游戏
Phase 1: 策划文档     ──→ interaction-design → gameplay-design → level-design → numerical-design
Phase 2: 项目搭建     ──→ project-scaffold → config-generator → 主场景 → InputMap
Phase 3: 系统开发     ──→ P0(输入/玩家/相机) → P1(战斗/敌人/关卡) → P2(UI/存档/音频)
Phase 4: 测试迭代     ──→ 运行验证 → 发现问题 → 定位模块 → 修复 → 再测试
```

## 环境部署流程（godot-deploy）

```
步骤1: 检查 Node.js >= 18
步骤2: 检查/构建 MCP Server (npm install + npm run build)
步骤3: 确认 .mcp.json 已注册到 Codebuddy
步骤4: 确认/下载 Godot Editor 到 ${WORKSPACE}/godot-editor/
步骤5: TCP 探测 9080 端口，引导用户启用 GodotMCP 插件
```

## 新建项目流程（godot-new）

```
1. 从用户原话推断 projectName 和 template
   - 模板: 2d-platformer / 3d-fps / default / empty
2. 复制模板到 ${WORKSPACE}/<projectName>
3. 注入 addons/godot_mcp/
4. 更新 project.godot (config/name + godot version)
5. 创建标准目录骨架 (assets/ data/ scenes/ scripts/)
6. 写入 active-game.json
7. 配置 .vscode LSP
8. 自动拉起 Godot 编辑器加载项目
```

## 场景修改流程（godot-dev 场景3）

修改对象分类处理：

| 修改对象 | 处理方式 |
|----------|---------|
| 场景/节点/属性/脚本 | 翻译成 `build_godot_scene` 的 root 树参数，一次性调用 |
| 独立 GDScript（autoload/工具） | 直接在 `${gameDir}/scripts/` 读写 .gd |
| 策划案/表格/Markdown | 直接在 `${gameDir}/docs/`、`${gameDir}/data/` 读写 |
| 图片/模型/音频等资源 | Copy-Item / Invoke-WebRequest 到 `${gameDir}/assets/` |

## 策划流程（game-planning）

```
Phase 0: 需求收集
  必问: 游戏类型 / 视角维度 / 目标平台 / 开发范围 / 参考游戏

Phase 1: 策划文档（按顺序生成）
  1.1 interaction-design  → docs/planning/interaction_design.md
  1.2 gameplay-design     → docs/planning/gameplay_design.md
  1.3 level-design        → docs/planning/level_design.md
  1.4 numerical-design    → docs/planning/numerical_design.md

  生成后展示摘要，等待用户确认。
```

## 原型/Demo/MVP 技能链

| 范围 | 时间 | 技能链 |
|------|------|--------|
| 原型 | 3天 | game-planning → project-scaffold → input-system → player-system → 测试场景 → 运行 |
| Demo | 2周 | 原型 + camera-system + 战斗系统 + 敌人AI + 关卡管理 + 基础UI |
| MVP | 2月 | Demo + save-system + audio-system + 多关卡 + 完整UI + 平衡调整 |

## 常见游戏类型快速参考

**2D 平台跳跃**: player-system(platformer_2d) + camera-system(smooth_follow) + input-system(move/jump/attack)
**2D RPG**: player-system(topdown_2d) + ui-system(inventory/dialog) + save-system(required)
**Roguelike**: player-system(varies) + procedural-generation + 元进度系统

## 工作区目录契约

```
${WORKSPACE}/
├── godot-editor/           ← Godot 编辑器（godot-deploy 下载）
├── active-game.json        ← 当前操作的游戏目录标记（godot-new 写入）
├── game1/                  ← 第1个游戏项目
│   ├── project.godot
│   ├── addons/godot_mcp/
│   └── scenes/ scripts/ assets/ data/ docs/
└── game2/                  ← 第2个游戏项目（再做一个时）
```
